# /code - 代码生成

## 触发条件
仅在用户通过 /prep 确认后，或手动输入 /code 时触发。
- 支持显式指定题目：`/code <题目名>`（如 `/code A题`）；未指定时读取 `shumo/.active_problem.txt` 中的当前题目。
- 状态文件为空且未指定题目名时，先询问题目名，不得默认猜测。
- 执行任何文件写入前，先在回复中列出目标目录树 `shumo/<题目名>/...` 供核对。

## 执行流程
0. 覆盖检查：若 `<题目名>/src/`（或按需的 scripts/、tests/）已存在同名 .m 文件，先备份为 `*.m.bak_<时间戳>`；在回复中列出"本次将创建/覆盖的文件清单"后再写入。
1. 致命错误检查清单：
   - 矩阵维度：`*` 与 `.*`、`'` 与 `.'`（复数转置）、broadcast 兼容性；
   - 循环：while 必须有终止条件 + 最大迭代次数护栏；for 循环内禁止修改迭代变量；
   - 递归：必须有出口条件；
   - 维度函数：size/length/numel 语义正确（length 对非向量矩阵返回 max(size)）；
   - 数值风险：除零、索引越界（end+1）、整型截断。
   - **8 项静态自检（2026-08-24 迭代新增，每个 .m 写完交付前逐项过一遍）**：
     ① 行/列向量：`1:N` 是行向量，拼接必须同列（用 `(1:N)'`）；② 约束行号统一 1 基、逐行递增无缝隙；
     ③ 锚点类右端 `1−值` 只写一次（子函数返回原始值，调用方做 1−）；④ 目标系数符号：max 转 min 取负后
     逐项核对（尤其 CVaR 的 η/v 与收益/成本项）；⑤ 隐式扩展维度（列向量×行向量产生矩阵）;
     ⑥ 链式索引 `a(b)(c)` 与脚本裸 `end`；⑦ 空 cell 提取（`find` 结果为 0×1 空，先判空再取）；
     ⑧ compose/cellstr 陷阱（compose 不接受 cellstr，用 sprintf 循环替代）。
2. 主程序存放于 `<题目名>/src/main_<模型名>.m`，包含 `clear; close all; clc;`。
3. 数据读取路径：主程序顶部统一定义
   `PROJ_ROOT = fullfile(fileparts(mfilename('fullpath')), '..');  % 题目根目录（脚本位于 <题目名>/src/）`
   后续一律 `fullfile(PROJ_ROOT, 'data', '文件名')`，保证脚本从任意目录启动均可正确读取（比 fullfile(pwd,'data',...) 更健壮，且保持同风格）。
4. 所有参数在脚本顶部集中定义，代码注释标注对应数学符号（公式编号）。
5. 子函数按功能拆分，存放于 `<题目名>/src/func_*.m`。

## 生成顺序（防止上下文溢出）
0. **小规模探针先行**（2026-08-24 迭代新增）：新模型先用微型数据（2 地块×3 作物×2 年、K=2）跑通装配与求解（秒级），验证通过后再用全量数据；探针脚本按需存 `<题目名>/scripts/probe_toy.m`（组内产物，不交付）。
1. 首先生成主程序 `main_<模型名>.m`（含完整函数接口与公式编号注释），等待编程手确认接口；
2. 接口确认后，逐个生成子函数 `func_*.m`；
3. 全部生成完成后自动进入 Phase 2（/test）。
单文件超过 300 行时拆分为多个子函数文件。

## 图像生成规范（2026-08-15 初版，2026-09-05 全面修订）
所有论文图统一调用 `<题目名>/src/func_fig_style.m` 应用全局样式；绘图代码按"一图一文件"
存放在 `<题目名>/src/plot_qX_<图名>.m`（从 `.claude/templates/` 复制模板），文件名与
`figures/qX_<图名>.png` 同名对应，独立可运行（读 outputs/final_results.mat，改图后单图
重生成即可，无需重跑主程序）；`run_all_figures.m` 汇总驱动。

### 字体与字号（防"AI 痕迹"）
- 图内文字 ≥14pt；图名与轴标签 16–18pt；刻度/图例 14–16pt；禁止默认 10pt 与"大图小字"。
- 图名用楷体加粗，轴标签/图例用宋体，英文与数字 Times New Roman；禁止整图黑体/微软雅黑。
  本机 Linux 出图前须 `listfonts` 确认楷体/宋体可用，缺则先安装（如 simkai.ttf / AR PL UKai）。

### 图名与文字标注
- 图名统一置于**图下方居中**（title 的 Position 下移至轴下方）；图内不带图号
  （图号由论文 LaTeX caption 统一编号，论文侧 caption 与图内图名一致、不重复）。
- 饼图/柱状图必须带数值或百分比标注，标注值由绘图数据现场计算（`round(pct,1)` 等），
  禁止硬编码，保证与论文正文数字同源一致。
- 数据标签偏移按**轴范围比例**（轴范围×2%），禁止固定数据单位偏移；散点隔点标注、
  标签交替上下错开、压点即跳过、跳过 0 值标签。
- 单位进轴标签（如"利润（万元）"），数据标签不带单位；数值格式统一小数位。
- 图内 LaTeX 记号：优先用 Unicode 符号（β、η、±）替代；必须用时显式设置
  `'Interpreter','latex'`，导出后目检无 `$...$` 残留或方块。

### 分层标注策略
- 柱数 ≤5：每柱柱顶标数值；柱数 6–12：只标最大值/关键柱，其余靠网格读数；
- 柱数 >12 或类名 >4 字：改横向柱状图，不标数值，配结果表；
- 分组柱：图例区分组 + 只标关键组，组内柱距 0.15；
- 饼图 ≤5 类：切片旁直接标百分比（沿角平分线外延 1.15 半径）；饼图 >5 类：改横向柱状图；
- 负值柱：标签放柱下方。

### 柱状图专项
- y 轴必须含 0（禁止截断基线，夸大差异是评审扣分点）；类别按降序或业务序排列；
- 柱宽 0.6–0.7、无边框或白色细边；对比图用"基准灰 + 最优强调色"；
- 有波动/多次运行的数据配误差棒（须有真实数据支撑，不得编造）；
- 双 y 轴柱线组合（如利润+增长率）：右轴刻度与线同色、图例注明左右轴归属，
  仅在量纲差异大且确需同图时使用。

### 图种类决策表（图型多样但"当且仅当必要"）
- 连续 x 趋势 → 折线+marker（按 x 升序连线）；类别比较（少）→ 柱状（按柱状图专项）；
- 类别多/名称长 → 横向柱状/帕累托（降序）；占比 ≤5 类 → 饼图（切片标 %）；占比 >5 类 → 横向柱状；
- 单组分布 → 直方图（长尾对数分箱，避免空柱）；多组分布对比 → 箱线图；
- 灵敏度 → 龙卷风图（横向、按影响排序、正负分向）；收敛/迭代 → semilogy（对数 y 轴）；
- 相关/矩阵 → 热图（单一连续色标）；量+率组合 → 双 y 轴柱线；
- 多指标评价/方案对比 → 权重雷达图；第三维承载真实数据（如年份×品类×利润）→ 三维柱状图；
  AHP 两两比较 → 判断矩阵（热图+格内数值）。
- 禁止：装饰性 3D、jet 彩虹色、截断 y 轴柱状图、>6 类饼图、图例覆盖数据。

### 调色板（固定 RGB，跨图一致）
主蓝 [76 114 176] | 主橙 [221 132 82] | 主绿 [85 168 104] | 主红 [196 78 82] |
紫 [129 114 179] | 灰 [140 140 140]。单图 ≤4 色；**同一变量/类别全论文同色**；
禁止 jet；连续量用 parula 或蓝白红发散；导出前灰度化目检可区分。
取色统一走 `func_fig_pal(idx)`，禁止散落硬编码 RGB。

### 导出与命名
- 出图前设 `Position` 为最终印刷尺寸（全宽 15cm / 半宽 7.5cm）；
- 输出 300dpi PNG（入论文）+ PDF（矢量存档）；EPS 仅在题目模板明确要求时生成；
- 每张图导出后立即 `close` 释放图形内存（3GB 环境）；
- 命名：`figures/qX_<图名>.png/.pdf` 与 `src/plot_qX_<图名>.m` 同名对应；
- 导出前目检：轴含义+单位 / 图例归属 / 标签不与柱点重叠且不被轴裁切 / 连线按 x 排序 /
  灰度可区分 / LaTeX 已渲染 / 放大到论文页宽后文字可读。

### 环境陷阱（R2026a）
- `bar()` 语义为"行=组、列=每组柱数"（与经典 MATLAB 相反），使用前以探针确认方向；
- `table()` 不按列拆分矩阵输入，用 `array2table`；
- 横轴标签过长旋转 45°。

## 代码注释规范（2026-08-15 工作流迭代新增）
1. 注释只保留**思路级**内容：函数头说明块（用途/输入输出/公式编号）、`%%` 分节、
   关键行的公式编号注释；
2. 删除实现细节注释（类型转换、缓存策略、防御性处理、调试记录）；
3. 注释中不写日期、裁定过程、参考来源等过程性信息；
4. 交付前执行注释精简复查与 AI 痕迹扫描（"值得注意/不难发现/首先/其次/最后"等
   表述不得出现在注释中，技术性用语除外）。
