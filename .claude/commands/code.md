# /code - 代码生成

## 触发条件
仅在用户通过 /prep 确认后，或手动输入 /code 时触发。
- 支持显式指定题目：`/code <题目名>`（如 `/code A题`）；未指定时读取 `shumo/.active_problem.txt` 中的当前题目。
- 状态文件为空且未指定题目名时，先询问题目名，不得默认猜测。
- 执行任何文件写入前，先在回复中列出目标目录树 `shumo/<题目名>/...` 供核对。

## 执行流程
0. 覆盖检查：若 `<题目名>/src/`（或按需的 scripts/、tests/）已存在同名 .m 文件，先备份为 `*.m.bak_<时间戳>`；在回复中列出"本次将创建/覆盖的文件清单"后再写入。
1. 致命错误检查清单：
   - 矩阵维度：`*` 与 `.*`、`'` 与 `.'`（复数转置）、broadcast 兼容性；
   - 循环：while 必须有终止条件 + 最大迭代次数护栏；for 循环内禁止修改迭代变量；
   - 递归：必须有出口条件；
   - 维度函数：size/length/numel 语义正确（length 对非向量矩阵返回 max(size)）；
   - 数值风险：除零、索引越界（end+1）、整型截断。
   - **8 项静态自检（2026-08-24 迭代新增，每个 .m 写完交付前逐项过一遍）**：
     ① 行/列向量：`1:N` 是行向量，拼接必须同列（用 `(1:N)'`）；② 约束行号统一 1 基、逐行递增无缝隙；
     ③ 锚点类右端 `1−值` 只写一次（子函数返回原始值，调用方做 1−）；④ 目标系数符号：max 转 min 取负后
     逐项核对（尤其 CVaR 的 η/v 与收益/成本项）；⑤ 隐式扩展维度（列向量×行向量产生矩阵）;
     ⑥ 链式索引 `a(b)(c)` 与脚本裸 `end`；⑦ 空 cell 提取（`find` 结果为 0×1 空，先判空再取）；
     ⑧ compose/cellstr 陷阱（compose 不接受 cellstr，用 sprintf 循环替代）。
2. 主程序存放于 `<题目名>/src/main_<模型名>.m`，包含 `clear; close all; clc;`。
3. 数据读取路径：主程序顶部统一定义
   `PROJ_ROOT = fullfile(fileparts(mfilename('fullpath')), '..');  % 题目根目录（脚本位于 <题目名>/src/）`
   后续一律 `fullfile(PROJ_ROOT, 'data', '文件名')`，保证脚本从任意目录启动均可正确读取（比 fullfile(pwd,'data',...) 更健壮，且保持同风格）。
4. 所有参数在脚本顶部集中定义，代码注释标注对应数学符号（公式编号）。
5. 子函数按功能拆分，存放于 `<题目名>/src/func_*.m`。

## 生成顺序（防止上下文溢出）
0. **小规模探针先行**（2026-08-24 迭代新增）：新模型先用微型数据（2 地块×3 作物×2 年、K=2）跑通装配与求解（秒级），验证通过后再用全量数据；探针脚本按需存 `<题目名>/scripts/probe_toy.m`（组内产物，不交付）。
1. 首先生成主程序 `main_<模型名>.m`（含完整函数接口与公式编号注释），等待编程手确认接口；
2. 接口确认后，逐个生成子函数 `func_*.m`；
3. 全部生成完成后自动进入 Phase 2（/test）。
单文件超过 300 行时拆分为多个子函数文件。

## 图像生成规范（2026-08-15 工作流迭代新增）
1. **图内标题不带图号**（图号由论文 LaTeX caption 统一编号，防止双编号冲突）；
   图内标题只保留主题描述（如"六品类蔬菜三年总销量占比"）。
2. **饼图/柱状图必须带数值或百分比标注**，且标注数值必须由绘图数据现场计算
   （`round(pct,1)` 等），禁止硬编码，保证与论文文本数字同源一致。
3. 输出 300dpi PNG + EPS 双格式；每张图导出后立即 `close` 释放图形内存（3GB 环境）；
   密集大图（如 12×12 散点矩阵）降为 150dpi。
4. 直方图对长尾数据用对数分箱，避免等宽分箱出现空柱；横轴过长标签旋转 45°。
5. 本环境 `bar()` 语义为"行=组、列=每组柱数"（与经典 MATLAB 相反），
   使用前先以探针确认方向；`table()` 不按列拆分矩阵输入，用 `array2table`。

## 代码注释规范（2026-08-15 工作流迭代新增）
1. 注释只保留**思路级**内容：函数头说明块（用途/输入输出/公式编号）、`%%` 分节、
   关键行的公式编号注释；
2. 删除实现细节注释（类型转换、缓存策略、防御性处理、调试记录）；
3. 注释中不写日期、裁定过程、参考来源等过程性信息；
4. 交付前执行注释精简复查与 AI 痕迹扫描（"值得注意/不难发现/首先/其次/最后"等
   表述不得出现在注释中，技术性用语除外）。
