# /test - 一致性测试与验证

## 触发条件
Phase 1 代码生成完成后自动触发，或用户手动输入。
- 支持显式指定题目：`/test <题目名>`（如 `/test A题`）；未指定时读取 `shumo/.active_problem.txt` 中的当前题目。
- 状态文件为空且未指定题目名时，先询问题目名，不得默认猜测。

## 目标
验证代码是否忠实地实现了建模手的数学模型，数据均来自 `<题目名>/data/`。

## 前置检查
- 对比 `<题目名>/src/` 各 .m 文件修改时间与 Phase 1 生成时间；发现人工修改的文件须在日志与报告中标注"人工修改文件：...（修改时间）"，并对其中的数学逻辑逐条复查映射。

## 测试脚本生成 (`<题目名>/tests/test_<模型名>.m`)
1. 读取 `<题目名>/data/` 下的原始数据。若数据行数 > 200，取前 200 行（或 10%）作为快速测试集。
2. 测试项：
   - **维度检查**：输入变量维度是否与映射表一致，输出变量维度是否与预期一致。
   - **特殊值检验**（按适用性勾选，每项须有可手算的预期输出）：
     ① 零向量/零矩阵（输出应为 0 或按公式定义值）；
     ② 单位向量/单位矩阵；
     ③ 变量上下界边界值；
     ④ 退化输入（重复行、奇异矩阵）；
     ⑤ 已知解析解用例（由建模手提供，相对误差 < 1e-6 为通过）。
   - **稳定性检验**：重复运行 10 次。确定性算法：输出标准差 < 1e-3 且相对标准差（std/|mean|）< 1%；随机/启发式算法（遗传算法、模拟退火、粒子群等）：多次运行最优值的相对波动 < 5% 且收敛水平一致为稳定。
   - **收敛性检验**（迭代算法）：满足以下任一即判收敛：
     ① 在最大迭代次数内满足算法自身终止条件（容差/梯度阈值）；
     ② 目标函数值序列最近 5 次迭代的相对变化 < 1e-6；
     ③ 收敛曲线（迭代次数 vs 目标函数值）保存至 `<题目名>/figures/`，报告附文件位置。
   - **参考解对比**（复杂模型必选）：建模手提供至少 1 组已知输入-输出对（解析解或可信数值解）；解析解相对误差 < 1e-6、数值参考解 < 1% 为通过。无参考解时进行解法交叉验证（不同步长/不同求解器结果一致性）。
3. 结果保存：`test_results` 存至 `<题目名>/outputs/test_results.mat`（save 使用 fullfile 绝对路径，避免默认路径依赖），diary 日志存至 `<题目名>/outputs/test_log.txt`。

## 执行方式
- 主路径：Claude 通过 `matlab -batch "run('<题目名>/tests/test_<模型名>.m')"` 自动执行并捕获输出（超时上限 300s）。
- 备用路径：同时生成 `<题目名>/run_test.sh` 一键脚本；若自动执行失败（MATLAB 未安装/无许可证/超时），由编程手执行 `bash <题目名>/run_test.sh` 并将输出粘贴回对话，Claude 据此继续判定。

## 判定
- 所有测试项通过 → 自动进入 /report。
- 任一测试项不通过 → 停止流转，请求编程手介入。报错内容固定包含：
  | 失败项 | 输入摘要 | 预期值 | 实际值 | 相对误差 |
  并附复现命令（如 `matlab -batch "run('<题目名>/tests/test_<模型名>.m')"`）、日志路径，以及**初步排查建议**：Claude 依据失败类型给出 2–4 条具体检查建议（例如：用 `size()` 检查变量维度是否与映射表一致、检查 `*` 与 `.*`、`'` 与 `.'` 是否用错、用 `dbstop if error` 定位出错行、检查参数是否在脚本顶部集中定义等）。失败详情同步写入 `<题目名>/outputs/failure_notes.md`（含失败项、预期 vs 实际、可能原因分析、排查建议、复现命令）。
- 重试机制：编程手修复后再次输入 `/test` 即可（幂等覆盖旧结果），无需重跑 /prep 与 /code。
