# /pcheck - 论文交付前检查

## 触发条件
全部章节撰写完成后调用，或用户输入 `/pcheck`。

## 执行流程
1. **确定题目**：支持显式参数；未指定时读取 `shumo/.active_problem.txt`。
2. **强制加载规范**：先 Read `paper-spec`、`paper-writer`、`paper-format`、`humanizer` 四个 SKILL.md。
3. **逐项检查（paper-spec §九清单）**：
   - [ ] 篇幅：估算总页数（正文约每 400~450 汉字/页 + 图表占页），是否在 25~30 页；
   - [ ] 图表引用：figures/ 中每张被引用图是否在正文中出现且图前有引导句、图后有解释句；
   - [ ] 数字一致性：正文全部数字与 `PAPER_HANDOFF.md` / `outputs/` 核对（逐条列差异）；
   - [ ] 去 AI 复查：按 humanizer 清单再扫一遍（重点：破折号、AI 高频词、三连排比、空洞结论）；
   - [ ] 反抄袭：与参考论文的表述相似度自查（标题句式/过渡语/解释措辞），相似处列出并改写；
   - [ ] 占位符：个人信息是否仍为【待填】；
   - [ ] LaTeX 语法：环境配对（\begin/\end）、$ 配对、特殊字符转义（_ & % #）、\input 路径存在；
   - [ ] 可打包性：paper/ 自包含（figures 已复制、无绝对路径引用）；
4. **输出检查报告**：逐项 PASS/FAIL，FAIL 项给出具体位置与修复建议。
5. **修复**：FAIL 项在征得编程手同意后修复，或由编程手决定保留。
6. **收尾**：更新 `.paper_progress.txt`（标记 completed），给出 README 中编译命令提醒。

## 注意
本机无 LaTeX 环境：无法实际编译，检查以静态语法核对为准；编译报错请用户将日志发回，我协助排错。
