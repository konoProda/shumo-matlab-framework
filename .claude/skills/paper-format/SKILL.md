# 竞赛论文通用格式参考（paper-format）

> 本规范由编程手基于同题论文结构惯例归纳提炼，为通用写作格式参考，
> 适用于 shumo/ 下所有题目的论文写作。只规定结构与呈现，不提供任何可直接照搬的表述。

## 一、摘要页格式

1. 一段式正文（或按问题分若干自然段），字数控制在整页以内；
2. 摘要末尾单独一行"关键词"，5~7 个，用空格分隔，必须包含本队模型的标志性方法名词；
3. 摘要正文必须回答五个问题：研究对象、核心问题、主要方法、关键结果、可信性说明。

## 二、章节组织模板（按顺序）

```
一、问题重述与分析
    1.1 问题背景          # 背景与数据条件单独成段
    1.2 问题重述          # 四问用 enumerate 分点列出
    1.3 问题分析          # 每问一个次级标题: 1.3.1 问题一的分析 ...
二、模型假设（假设和合理性说明）
                        # 每条假设独立编号, 每条附依据句
三、符号说明              # 表格: 符号|意义|单位; 注明"其他符号在下文首次出现时说明"
四~七、问题一~四的模型建立与求解
八、模型的检验与灵敏度分析   # 检验对象/指标/结论明确
九、模型的评价、改进与推广    # 四件套: 优点/缺点/改进/推广
十、参考文献
附录A~：支撑材料清单/代码节选/中间结果
```

两种变体（均常见，择一保持一致）：
- 数据预处理**独立成章**（放在符号说明之后、各问之前），各问只引用；
- 数据预处理**并入各问**（每问开头一小节"数据准备"，仅写本问增量处理）。

## 三、每个问题章节的内部四段式

1. **数据准备与处理**：本问用到的数据来源、清洗、口径定义（可引用全局预处理，不重复全文）；
2. **模型建立**：目标界定 → 变量与参数 → 假设 → 模型结构 → 约束 → 参数确定 → 求解策略，
   公式编号（1）（2）...，每个公式后紧跟变量解释；
3. **求解与结果**：求解方法一句话 + 结果表（注明单位）+ 关键数字加粗或在正文点出；
4. **结果分析**：先给结论，再引用图表，再解释原因，最后说明实际含义。解释必须联系现实
   （季节、消费习惯、经营规律），不得只复述数字。

## 四、图表规范

1. 编号连续：图1、图2...，表1、表2...，正文必须引用；
2. 每张图：图前引导句（"图X展示了..."）+ 图 + 图后解释句（该图支撑了什么结论）；
3. 标题自解释（含变量与单位，如"各品类月销售量（kg）"），禁止"结果图""分析图"式标题；
4. 双面板图用 (a)(b) 标注并分别解释；
5. 表下注明单位行（如"补货量单位为kg，定价单位为元/kg"）；
6. 颜色克制，灰度打印可区分。

## 五、检验与灵敏度章节规范

1. 检验对象、检验指标、检验结论三者明确，不得"模型较好"式空话；
2. 优化类模型的检验组合：约束满足性核对、结果与公式独立重算、方案对比、
   参数灵敏度（±5%/~10%）、与历史/往年同期对比；
3. 灵敏度结果优先用表格呈现；若画图，数据点须含基准点并升序连线；
4. 检验章节可引用编程侧的自动化测试结论（如"26 项一致性测试全部通过"）作为支撑。

## 六、模型评价四件套

1. 优点：落到模型结构、数据利用、参数可解释性、求解复杂度、鲁棒性维度，每条给理由；
2. 缺点：必须具体（如"某品类拟合优度低""预测未考虑天气"），并指出影响；
3. 改进：针对每条缺点给出可操作的改进方向（对应问题四的数据建议，形成呼应）；
4. 推广：说明可迁移场景与需要替换的模块。

另：问题三章末建议加"与问题二的结果对比"小节（单品方案与品类方案同一日的利润/结构对比，
说明细化到单品层面后的利润损失与品类均衡变化），这是评审关注的承上启下点。

## 七、附录组织

1. 附录A：支撑材料文件清单（数据、代码、结果表一一列出）；
2. 附录B：代码节选（每段 ≤15~20 行，配一行说明；完整代码指向支撑材料）；
3. 附录C：中间结果（完整排名表、敏感性明细等正文放不下的表）。

## 八、编号与引用规范

1. 章节编号："一、""1.1""1.1.1"；公式编号按章或全篇连续（1）（2）...；
2. 图表编号全篇连续；参考文献按正文引用顺序编号；
3. 术语全篇统一（如"成本加成定价"不得混用"加成定价/加价"）。
