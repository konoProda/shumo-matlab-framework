## 3️⃣ 问题 1 – 蔬菜品类/单品间的关联度（数理统计类）

### 3.1 建模目标  
1. 描述每个品类（或单品）的日销量分布（均值、方差、偏度、峰度）。  
2. 计算 **斯皮尔曼秩相关系数** \(\rho_{ij}\) 衡量两者之间的单调相关强度，并进行显著性检验。  
3. 通过热力图 + 层次聚类展示关联结构，为后续协同补货提供依据。

### 3.2 关键变量与数据  
- \(q_{i,t}\)：第 \(i\) 类/单品在第 \(t\) 天的销量（kg），来源于 `daily_sales.csv` 或 `category_daily.csv`。  
- 若当天未售出，填充为 0 以保证序列长度一致。  

### 3.3 斯皮尔曼秩相关公式  

\[
\rho_{ij}=1-\frac{6\displaystyle\sum_{t=1}^{T}\bigl(R_i(t)-R_j(t)\bigr)^2}{T\bigl(T^2-1\bigr)},
\]

- \(R_i(t)\) 为 \(q_{i,t}\) 在其序列中的秩（从 1 开始）。  
- 显著性检验（近似 t‑分布）  

\[
t=\rho_{ij}\sqrt{\frac{T-2}{1-\rho_{ij}^{2}}},\qquad
p=2\bigl(1-\Phi_{t_{T-2}}(|t|)\bigr).
\]

### 3.4 结果解释指针  
| \(\rho_{ij}\) 范围 | 含义 |
|-------------------|------|
| \(\rho>0\) | 同向变化，可能是 **互补** 或 **同季节** 需求。 |
| \(\rho<0\) | 方向相反，暗示 **替代** 关系。 |
| \(|\rho|>0.6\) 且 \(p<0.01\) | **强关联**，在后续补货模型中建议同步进货或相邻陈列。 |

## 4️⃣ 问题 2 – 品类层面补货与定价（优化类）  

### 4.1 决策变量  

| 符号 | 含义 | 类型 |
|------|------|------|
| \(x_{c,t}\) | 第 \(t\) 天对品类 \(c\) 的补货量（kg） | 连续 \(\ge0\) |
| \(p_{c,t}\) | 第 \(t\) 天的零售单价（¥/kg） | 连续（若离散化则为组合变量） |

### 4.2 参数  

| 符号 | 含义 | 获取方式 |
|------|------|----------|
| \(w_{c,t}\) | 当日批发价（¥/kg） | `wholesale_price.csv` 按品类加权平均 |
| \(\bar\ell_c\) | 品类平均损耗率（小数） | `product_info.csv` 中对应单品损耗率均值 |
| \(\hat w_{c,t}=w_{c,t}(1+\bar\ell_c)\) | 计入损耗后的有效成本 | 直接计算 |
| \(a_c,\;b_c\) | 需求‑价格线性回归系数：\(D_c(p)=a_c+b_c p\) | 对 `daily_sales.csv` 进行最小二乘回归 |
| \(p_c^{\min},p_c^{\max}\) | 价格上下限（历史最小/最大） | `daily_sales.csv` 中的 `unit_price` |
| \(V_t\) | 当天可用展示空间（或体积） | 业务提供或经验估计 |
| \(s_c\) | 每千克所占展示面积（默认 1） | 业务经验 |

### 4.3 约束（逐条说明）  

1. **需求上限**（防止补货超出需求）  
   \[
   x_{c,t}\le a_c+b_c\,p_{c,t},\qquad\forall c,t.
   \]
2. **价格区间**  
   \[
   p_c^{\min}\le p_{c,t}\le p_c^{\max},\qquad\forall c,t.
   \]
3. **展示空间**（若有）  
   \[
   \sum_{c}s_c\,x_{c,t}\le V_t,\qquad\forall t.
   \]
4. **非负**  
   \[
   x_{c,t}\ge0,\qquad\forall c,t.
   \]

### 4.4 目标函数（利润最大化）  

\[
\boxed{\displaystyle 
\max Z=\sum_{t=1}^{7}\sum_{c}\bigl(p_{c,t}-\hat w_{c,t}\bigr)\,x_{c,t}
}
\]

> 该目标本身是 **线性的**，前提是 \(p_{c,t}\) 为已知常数。为保持线性，可采用两种实现思路：

### 4.5 线性化方案  

| 方案 | 思路 | 关键点 |
|------|------|--------|
| **A（固定加成）** | 使用历史平均加成率 \(\eta_c\)，设 \(p_{c,t}=(1+\eta_c) w_{c,t}\)，从而 `p` 为常数。 | 仅需求解补货量 \(x_{c,t}\)，模型即为标准 **LP**。 |
| **B（价格离散化）** | 预设 \(K\) 种可能售价 \(\{p_c^{(k)}\}\)，引入二元变量 \(z_{c,t}^{(k)}\) 表示当天选取第 \(k\) 种价。 | 形成 **MILP**（规模仍很小，\(6\times7\times K\) 变量），可保留定价灵活性。 |

### 4.6 求解方法  

- **方案 A**：`scipy.optimize.linprog`、`pulp`（Simplex）或 `Gurobi`/`CPLEX` 的 LP 求解器。  
- **方案 B**：`Gurobi`、`CPLEX`、`CBC`、`SCIP`（MILP）均能在秒级完成求解。

## 5️⃣ 问题 3 – 单品层面整数优化（MILP）  

### 5.1 决策变量  

| 符号 | 含义 | 类型 |
|------|------|------|
| \(y_i\) | 单品 \(i\) 是否上架（1‑上，0‑下） | binary |
| \(x_i\) | 单品 \(i\) 的补货量（kg） | continuous \(\ge0\) |
| \(p_i\) | 单品 \(i\) 的零售单价（¥/kg） | continuous |
| （可选）\(z_i^{(k)}\) | 价格离散化二元变量（\(k=1,\dots,K\)） | binary |

### 5.2 参数  

| 符号 | 含义 | 获取方式 |
|------|------|----------|
| \(w_i\) | 单品批发价（¥/kg） | `wholesale_price.csv` 均值 |
| \(\ell_i\) | 单品损耗率（小数） | `product_info.csv` |
| \(a_i,b_i\) | 需求‑价格线性回归系数（单品） | 对 `daily_sales.csv` 按单品回归 |
| \(p_i^{\min},p_i^{\max}\) | 单品历史最低/最高单价 | `daily_sales.csv` |
| \(s_i\) | 单品每千克占用展示面积（默认 1） | 业务经验 |
| \(V\) | 当天总体展示空间上限 | 业务提供 |
| \(L=27,\;U=33\) | 上架单品数量的下、上限 | 题目要求 |
| \(M\) | 大 \(M\) 常数（如 100 kg） | 用于二元‑连续关联约束 |

### 5.3 约束  

1. **商品数目**  
   \[
   L\le\sum_i y_i\le U.
   \]
2. **最小陈列量**（仅在上架时生效）  
   \[
   x_i\ge 2.5\,y_i,\qquad\forall i.
   \]
3. **需求上限**  
   \[
   x_i\le a_i+b_i\,p_i,\qquad\forall i.
   \]
4. **价格区间**  
   \[
   p_i^{\min}\,y_i\le p_i\le p_i^{\max}\,y_i,\qquad\forall i.
   \]
5. **展示空间**  
   \[
   \sum_i s_i\,x_i\le V.
   \]
6. **二元‑连续关联（若离散化）**  
   \[
   \sum_{k=1}^{K}z_i^{(k)}=y_i,\qquad
   p_i=\sum_{k}p_i^{(k)}z_i^{(k)},
   \]
   \[
   x_i\le\sum_{k}\bigl(a_i+b_i\,p_i^{(k)}\bigr)z_i^{(k)}.
   \]
   同时加入  
   \[
   x_i\le M\,y_i,\qquad x_i\ge0.
   \]

### 5.4 目标函数  

\[
\boxed{\displaystyle 
\max Z=\sum_{i}\bigl(p_i-w_i(1+\ell_i)\bigr)\,x_i
}
\]

- 若采用离散化，则目标可写为  
  \[
  \max Z=\sum_{i}\sum_{k}\bigl(p_i^{(k)}-w_i(1+\ell_i)\bigr)\,x_i^{(k)}.
  \]

### 5.5 求解技术  

- 使用 **MILP 求解器**（Gurobi / CPLEX / CBC / SCIP）。  
- 变量规模约为：  
  - 二元变量：\(N\)（上架）\(+\;N\times K\)（价格）  
  - 连续变量：\(2N\)（补货量、售价）  
  - 对于本题的单品数约 200，求解时间通常 < 10 s。

## 6️⃣ 问题 4 – 进一步需要采集的关键数据  

| 推荐数据 | 采集方式 | 与模型的直接关联 | 说明 |
|----------|----------|-------------------|------|
| **每日库存（期初/期末）** | POS/ERP 实时库存 | 用于 **实际可供量**、**废弃成本**、**滚动补货** | 消除 “库存全为 0” 假设 |
| **单品保质期（天）** | 供应商标签或系统字段 | 决定 **安全库存**、**提前消耗** 约束 | 防止保鲜期短导致的浪费 |
| **促销/折扣信息** | 销售系统的折扣字段 | 将折扣视为 **离散价格水平**，提升需求回归精度 | 当前样本中折扣全为“否”，实际业务常有 |
| **天气/气象数据**（温度、湿度、降雨） | 气象局 API（如中国气象网） | 作为 **外生解释变量** 捕捉 **天气弹性** | 蔬菜需求对天气高度敏感 |
| **客流/交易笔数** | 门店入口计数或 POS 交易计数 | 用于 **需求规模因子**，帮助解释异常波动 | 与销量一起建多元回归更稳健 |
| **竞争对手同类商品售价** | 市场调研或爬虫采集 | 用于 **价格竞争模型**（贝叶斯层次模型） | 当前模型只考虑内部成本 |
| **商品质量分级**（外观等级、重量区间） | 进货检验记录 | 不同质量对应不同 **售价** 与 **损耗率**，可细分子品种建模 | 现有数据仅有统一编码 |
| **货架/冷链展示面积** | 店面布局图测量 | 空间约束中的系数 \(s_i\) 与总容量 \(V\) | 目前使用统一面积系数为 1 |
| **供应商最小起订量、交货周期、价格波动** | 合同或供应链系统 | 为 **补货可行性** 加入 **最小批量** 与 **提前期** 约束 | 现模型默认任意数量可即时补货 |
| **时序损耗率** | 每日盘点系统 | 使 \(\ell_i\) 成为随时间变化的参数 \(\ell_{i,t}\)，提升成本估算精准度 | 当前仅用历史均值 |

> **建议**：将上述数据统一建模为 **日‑品‑维度宽表**（如 `full_data.csv`），便于后续特征工程与模型迭代。

## 7️⃣ 关键假设、适用范围与潜在风险  

| 假设 | 说明 | 潜在风险 |
|------|------|----------|
| **需求对价格线性** \(D(p)=a+b\,p\) | 仅在短期（≤1 周）且价格波动不大时成立 | 大幅折扣或促销会出现非线性弹性，需重新拟合 |
| **损耗率为常数** \(\ell_i,\ \bar\ell_c\) | 使用最近 30 天均值 | 损耗随温度、存放时长变化，可能导致成本偏差 |
| **价格区间为历史最小/最大** | 防止不合理售价 | 若历史区间过窄，限制利润提升空间 |
| **空间容量 \(V_t\) 已知且硬约束** | 体现货架/冷链上限 | 实际容量估计不准会导致不可实现的方案 |
| **库存可即时补足** | 预设补货无提前期 | 若有交货提前期，应加入 **提前期约束** |
| **客流、天气对需求的影响可忽略** | 当前模型未显式加入 | 在异常天气或节假日会导致预测偏差 |
| **同品类单品间需求相互独立** | 关联度仅用于后续分析 | 实际上存在 **互补/替代** 效应，若需要可在 MILP 中加入协同约束 |

## 8️⃣ 典型求解流程（可直接写入论文方法章节）  

1. **数据清洗**  
   - 执行表 1 中的清洗脚本，输出 4 张 CSV。  
2. **需求回归**  
   - 对每个品类/单品使用最小二乘回归 `quantity = a + b·price`，记录均值、显著性。  
3. **问题 1统计分析**  
   - 计算斯皮尔曼相关系数矩阵，显著性检验，做层次聚类并绘制热力图。  
4. **构建优化模型**  
   - **问 2**：选择方案 A（固定加成）或方案 B（离散价格）生成 LP/MILP。  
   - **问 3**：构建完整的 MILP（含二元选址、最小陈列约束）。  
5. **求解**  
   - 使用 `pulp`、`gurobipy` 等求解器；LP 采用 Simplex/内点，MILP 采用分支定界。  
6. **结果输出**  
   - 生成每日‑品类（问 2）或单品（问 3）的 **补货量 & 建议售价** 表格；统计 **总利润、空间利用率**。  
7. **敏感性/稳健性分析**  
   - 逐个调节关键参数（损耗率、空间上限、价格上下限），记录目标函数变化，评估模型对不确定性的鲁棒性。  
8. **模型局限与改进方向**  
   - 根据第 4 问的数据建议，讨论加入库存、保鲜期、天气等因素的可能改进路径。
