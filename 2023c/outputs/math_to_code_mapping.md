## 3. 目标函数

| 问题 | 表达式 | 公式编号 | 代码落点 |
|------|--------|---------|---------|
| 问题 2 | max Z = Σ_{t=1..7} Σ_c (p_{c,t} − ŵ_{c,t})·x_{c,t} | (4.4) | `func_objective_q2` |

| 问题 3（离散化） | max Z = Σ_i Σ_k (p_i^{(k)} − w_i(1+ℓ_i))·x_i^{(k)} | (5.4') | 同上（备选） |

## 4. 约束条件（逐条编号）

**问题 2（品类）：**
1. 需求上限：x_{c,t} ≤ a_c + b_c·p_{c,t}（4.3.1）
2. 价格区间：p_c^min ≤ p_{c,t} ≤ p_c^max（4.3.2）
3. 展示空间（若有）：Σ_c s_c·x_{c,t} ≤ V_t（4.3.3）
4. 非负：x_{c,t} ≥ 0（4.3.4）

**问题 3（单品）：**
1. 商品数目：L ≤ Σ_i y_i ≤ U（5.3.1）
2. 最小陈列量：x_i ≥ 2.5·y_i（5.3.2）
3. 需求上限：x_i ≤ a_i + b_i·p_i（5.3.3）
4. 价格区间：p_i^min·y_i ≤ p_i ≤ p_i^max·y_i（5.3.4）
5. 展示空间：Σ_i s_i·x_i ≤ V（5.3.5）
6. 离散化关联：Σ_k z_i^{(k)} = y_i；p_i = Σ_k p_i^{(k)} z_i^{(k)}；x_i ≤ Σ_k (a_i + b_i p_i^{(k)}) z_i^{(k)}；x_i ≤ M·y_i；x_i ≥ 0（5.3.6）
