### 3.3 目标函数

$$\max W = \sum_{t}\sum_{s}\sum_{(i,j,s)\in\Omega}\left( P_{j,k(i),s}\,q^{norm}_{i,j,s,t} + \gamma P_{j,k(i),s}\,q^{disc}_{i,j,s,t} - C_{i,j,s}\,x_{i,j,s,t}\right)$$

- 情况(1) 滞销：γ=0 且强制 q_disc≡0（超产无收入、全额计成本）
- 情况(2) 半价：γ=0.5

### 3.4 约束条件

| 编号 | 公式 | 含义 |
|---|---|---|
| C1-1 | $Q_{i,j,s,t}=Y_{i,j,s}\cdot x_{i,j,s,t}$ | 单地块产量定义（等式） |
| C1-2 | $\sum_{i:(i,j,s)\in\Omega} q^{norm}_{i,j,s,t} \le D_{j,s}$ | 全村正常价销量上限 |
| C1-3 | $q^{norm}_{i,j,s,t}+q^{disc}_{i,j,s,t}\le Q_{i,j,s,t}$ | 单地块产销平衡（情况2 下最优自然取等） |
| C1-4 | $\sum_{j:(i,j,s)\in\Omega} x_{i,j,s,t}\le A_i$ | 地块面积上限 |
| C1-5 | $\delta A_i u_{i,j,s,t}\le x_{i,j,s,t}\le A_i u_{i,j,s,t}$ | 最小种植比例 + 种植开关 |
| C1-6a | $u_{i,j,s,t}+u_{i,j,s,t-1}\le 1$，t∈T（含 2023 常数） | 连作禁止（跨年同季） |
| C1-6b | $u_{i,j,1,t}+u_{i,j,2,t}\le 1$，i∈{27..54} | 连作禁止（年内跨季：水浇地+大棚） |
| C1-6c | $u_{i,j,2,t-1}+u_{i,j,1,t}\le 1$，i∈{51..54} | 连作禁止（智慧大棚跨年跨季） |
| C1-7 | $\sum_{\tau=t-2}^{t}\sum_s\sum_{j\in J_{bean}}u_{i,j,s,\tau}\ge 1$，**t∈{2025..2030}** | 三年一熟豆类轮作（B1 修正：窗口自 2023 起） |
| C1-8 | $\sum_{i:(i,j,s)\in\Omega}u_{i,j,s,t}\le N_j^{max}$ | 集中种植上限 |

- 求解：`intlinprog`（稀疏装配），分别求情况(1)/(2)，回填 `result1_1.xlsx`/`result1_2.xlsx`。
- 规模：29,736 变量（14,868 连续 + 7434 二值 + 7434 连续 q）+ ~3.8 万约束，分钟级。

## 4. 问题 2 映射（两阶段随机规划 SAA-CVaR）

### 4.1 随机参数生成（逐年独立抽样、复利累积）

| 编号 | 参数 | 分布与累积公式 | 代码变量名 |
|---|---|---|---|
| P2-1 | $D_{j,s,t}(\omega)$ | 小麦(6)/玉米(7)：$g_{j,t}\sim U(0.05,0.10)$；其他：$U(-0.05,0.05)$；$D_t=D_{2023}\prod_{\tau=2024}^{t}(1+g_\tau)$ | `demand_w(j,s,t,w)` |
| P2-2 | $C_{i,j,s,t}(\omega)$ | $g_c\sim N(0.05,0.01^2)$；$C_t=C_{2023}\prod(1+g_{c,\tau})$ | `cost_w(idx,t,w)` |
| P2-3 | $P_{j,k(i),s,t}(\omega)$ | 粮食 rate=0；蔬菜 $g_p\sim N(0.05,0.01^2)$；食用菌 38-40 $d_p\sim U(0.01,0.05)$（负向）；羊肚菌固定 −5%；自 2023 价复利 | `price_w(idx,t,w)` |
| P2-4 | $Y_{i,j,s,t}(\omega)$ | $\xi_{j,t}\sim U(-0.10,0.10)$；灾害：露天 i≤34 每地块每年 10% 独立触发，**每地块独立抽样** $\theta_{i,t}(\omega)\sim U(0.30,0.40)$（B5 修正）；大棚 θ=0；$Y=Y_{2023}(1+\xi)(1-\theta\mathbb{I}_{灾害})$ | `yield_w(idx,t,w)` |

### 4.2 SAA-CVaR 模型

- 情景净利润：$\Pi_t(x,\omega)=\sum_s\sum_{\Omega}[P_{j,k(i),s,t}(\omega)q^{norm}_{i,j,s,t}(\omega)+0.5P\,q^{disc}(\omega)-C_{i,j,s,t}(\omega)x_{i,j,s,t}]$，$\mathrm{Loss}_t=-\Pi_t$
- CVaR（α=0.95）：$\mathrm{CVaR}_t=\eta_t+\frac{1}{0.05K}\sum_\omega v_t(\omega)$；$v_t(\omega)\ge \mathrm{Loss}_t-\eta_t$，$v_t(\omega)\ge 0$
- 目标：$\max\sum_t\left(\frac{1}{K}\sum_\omega\Pi_t(x,\omega)-\lambda\,\mathrm{CVaR}_t\right)$，λ=0.1（敏感性 {0,0.1,0.5}）
- 约束：第一阶段 x,u 满足 C1-4~C1-8 全部刚性约束；每情景下 C1-2/C1-3 的随机版本：$\sum_i q^{norm}(\omega)\le D_{j,s,t}(\omega)$；$q^{norm}(\omega)+q^{disc}(\omega)\le Y_{i,j,s,t}(\omega)x_{i,j,s,t}$；产销按半价规则（γ=0.5）
- 第二阶段变量（每情景）：`q_norm_w`、`q_disc_w`（1062×7×K×2）；`eta(t)`、`v_tail(t,w)`
