# 农作物的种植策略数学模型与算法设计文档

---

### 一、 模型假设与基础约定

1. **基准供需平衡假设**：假设 2023 年全村各种农作物的实际总产量即为其基准预期销售量 $D_{j,s,2023}$[cite: 2, 3, 4]。
2. **多维价格与成本查表**：严格根据（作物 $j$、地块类型 $k$、季次 $s$）三元组查表确定销售单价 $P_{j,k,s}$ 和种植成本 $C_{j,k,s}$，智慧大棚比普通大棚及水浇地高出的约 20% 价格溢价直接在各对应地块单价中体现[cite: 2, 3, 5]。
3. **缺失数据等价平补**：智慧大棚第一季缺失的蔬菜亩产与成本数据，采用普通大棚第一季对应蔬菜的数据进行平补[cite: 2, 3, 5]。
4. **两阶段时序决策**：种植面积分配 $x$ 与地块种植决策 $u$ 属于事前第一阶段决策；产销匹配量（正常售出 $q^{\text{norm}}$ 与打折售出 $q^{\text{disc}}$）为随机环境展开后的事后第二阶段决策[cite: 3, 5]。
5. **灾害作用范围**：干旱、暴雨等极端气候仅作用于露天耕地，大棚因具备人工环境调控能力不计直接减产[cite: 4, 5]。

### 二、 符号与集合说明

*   $t \in T = \{2024, 2025, \dots, 2030\}$：规划年份集合（$t=2023$ 为历史基准年）[cite: 1, 3, 5]。
*   $i \in I = \{1, 2, \dots, 54\}$：地块集合（$1 \sim 34$ 为露天耕地，$35 \sim 50$ 为普通大棚，$51 \sim 54$ 为智慧大棚）[cite: 1, 2, 5]。
*   $k(i) \in K_{\text{type}}$：地块 $i$ 对应的地块类型映射[cite: 1, 2, 5]。
*   $j \in J = \{1, 2, \dots, 41\}$：作物种类集合；豆类作物子集为 $J_{\text{bean}} \subset J$[cite: 2, 3, 5]。
*   $s \in S = \{1, 2\}$：种植季次（单季作物取 $s=1$；双季蔬菜与大棚取 $s \in \{1, 2\}$）[cite: 1, 3, 5]。
*   $\Omega = \{(i, j, s) \mid \text{地块 } i \text{ 的第 } s \text{ 季适宜种植作物 } j\}$：适宜种植的三元组集合[cite: 2, 3, 5]。
*   $\omega \in \mathcal{W} = \{1, 2, \dots, K\}$：随机抽样情景集合，每个情景概率 $p_\omega = \frac{1}{K}$（基准取 $K=50 \sim 100$）[cite: 2, 3, 5]。

### 三、 问题 1：确定性多周期混合整数线性规划模型（MILP）

#### 1. 变量与参数定义
*   **决策变量**：
    *   $x_{i,j,s,t} \ge 0$：第 $t$ 年第 $s$ 季在地块 $i$ 种植作物 $j$ 的面积（亩）[cite: 3, 5]。
    *   $u_{i,j,s,t} \in \{0, 1\}$：0-1 变量，表示第 $t$ 年第 $s$ 季在地块 $i$ 是否种植作物 $j$[cite: 2, 3, 5]。
    *   $q_{i,j,s,t}^{\text{norm}} \ge 0$：第 $t$ 年第 $s$ 季地块 $i$ 上产出的作物 $j$ 按正常价格销售的数量（斤）[cite: 3, 5]。
    *   $q_{i,j,s,t}^{\text{disc}} \ge 0$：第 $t$ 年第 $s$ 季地块 $i$ 上产出的作物 $j$ 降价 50% 销售的数量（斤）[cite: 3, 5]。
*   **输入参数**：
    *   $A_i$：地块 $i$ 的面积（亩）[cite: 3, 5]。
    *   $Y_{i,j,s}$：作物 $j$ 在地块 $i$ 第 $s$ 季的亩产量（斤/亩）[cite: 2, 3, 5]。
    *   $C_{i,j,s}$：作物 $j$ 在地块 $i$ 第 $s$ 季的种植成本（元/亩）[cite: 2, 3, 5]。
    *   $P_{j,k(i),s}$：作物 $j$ 在地块 $i$ 类型 $k(i)$ 下第 $s$ 季的销售单价（元/斤）[cite: 3, 5]。
    *   $D_{j,s}$：作物 $j$ 第 $s$ 季的全村预期销售量（等于 2023 年对应季全村总产量）[cite: 2, 3, 5]。
    *   $\delta = 0.10$：单地块单作物最小种植面积比例（满足种植不宜太小，即 $\ge 10\% A_i$）[cite: 2, 3, 5]。
    *   $N_j^{\max}$：作物 $j$ 每季最大允许分散种植的地块数，具体取值设定为：
        $$N_j^{\max} = \begin{cases} 4, & j \in \{1, \dots, 15\} \text{（大宗粮食类）} \\ 3, & j = 16 \text{（水稻）} \\ 8, & j \in \{17, \dots, 37\} \text{（蔬菜瓜果类）} \\ 6, & j \in \{38, \dots, 41\} \text{（食用菌类）} \end{cases}$$[cite: 3, 4, 5]

#### 2. 数学模型构建
*   **总产量计算**：
    $$Q_{i,j,s,t} = Y_{i,j,s} \cdot x_{i,j,s,t}, \quad \forall (i,j,s) \in \Omega, t$$[cite: 3, 5]

*   **目标函数（最大化 2024~2030 年总利润）**：
    $$\max W = \sum_{t \in T} \sum_{s \in S} \sum_{(i,j,s) \in \Omega} \left( P_{j,k(i),s} \cdot q_{i,j,s,t}^{\text{norm}} + \gamma P_{j,k(i),s} \cdot q_{i,j,s,t}^{\text{disc}} - C_{i,j,s} \cdot x_{i,j,s,t} \right)$$[cite: 2, 3, 5]
    *   **情况 (1) 滞销**：设置 $\gamma = 0$ 且强制 $q_{i,j,s,t}^{\text{disc}} = 0$[cite: 1, 3, 5]。超产部分无销售收益，全额结算种植成本[cite: 3, 5]。
    *   **情况 (2) 半价出售**：设置 $\gamma = 0.5$[cite: 1, 3, 5]。

*   **全村产销平衡与需求上限约束**：
    $$\sum_{i: (i,j,s) \in \Omega} q_{i,j,s,t}^{\text{norm}} \le D_{j,s}, \quad \forall j, s, t$$[cite: 3, 5]
    $$q_{i,j,s,t}^{\text{norm}} + q_{i,j,s,t}^{\text{disc}} \le Q_{i,j,s,t}, \quad \forall (i,j,s) \in \Omega, t$$[cite: 3, 5]
    $$q_{i,j,s,t}^{\text{norm}} \ge 0, \quad q_{i,j,s,t}^{\text{disc}} \ge 0, \quad \forall (i,j,s) \in \Omega, t$$[cite: 3, 5]

*   **地块面积与种植下限约束**：
    $$\sum_{j: (i,j,s) \in \Omega} x_{i,j,s,t} \le A_i, \quad \forall i, s, t$$[cite: 2, 3, 5]
    $$\delta A_i \cdot u_{i,j,s,t} \le x_{i,j,s,t} \le A_i \cdot u_{i,j,s,t}, \quad \forall (i,j,s) \in \Omega, t$$[cite: 2, 3, 5]

*   **防重茬（禁止连作）线性约束**：
    *   跨年同季（含 2023 年已知历史 $u_{i,j,s,2023}$ 作为先验常数）：
        $$u_{i,j,s,t} + u_{i,j,s,t-1} \le 1, \quad \forall (i,j,s) \in \Omega, t \in T$$[cite: 2, 3, 5]
    *   年内跨季连作（水浇地与大棚）：
        $$u_{i,j,1,t} + u_{i,j,2,t} \le 1, \quad \forall i \in \{27, \dots, 54\}, j, t \in T$$[cite: 2, 3, 5]
    *   智慧大棚跨年跨季连作（第 $t-1$ 年第二季 $\to$ 第 $t$ 年第一季）：
        $$u_{i,j,2,t-1} + u_{i,j,1,t} \le 1, \quad \forall i \in \{51, \dots, 54\}, j, t \in T$$[cite: 3, 5]

*   **三年一熟豆类轮作约束（涵盖 2023 年历史）**：
    $$\sum_{\tau = t-2}^{t} \sum_{s \in S} \sum_{j \in J_{\text{bean}}} u_{i,j,s,\tau} \ge 1, \quad \forall i, t \in T$$[cite: 2, 3, 5]

*   **集中种植约束（带具体参数）**：
    $$\sum_{i: (i,j,s) \in \Omega} u_{i,j,s,t} \le N_j^{\max}, \quad \forall j, s, t$$[cite: 3, 4, 5]

#### 3. 求解算法与 MATLAB 实现
*   **求解器**：调用 MATLAB 内置的 `intlinprog` 分支割平面求解器[cite: 5]。
*   **回填流程**：构建稀疏矩阵装配约束求解，将结果自动填入 `result1_1.xlsx` 和 `result1_2.xlsx` 模板中[cite: 1, 2, 3, 5]。

### 四、 问题 2：含波动与 CVaR 风险度量的两阶段随机规划模型

#### 1. 不确定性参数生成与复利累积规则
在情景 $\omega \in \mathcal{W}$ 下，各随机参数逐年独立抽样并复利累积[cite: 3, 5]：
1.  **预期销售量 $D_{j,s,t}(\omega)$**：
    *   小麦、玉米（$j \in \{6, 7\}$）：$g_{j,t}(\omega) \sim U(0.05, 0.10)$[cite: 1, 2, 3, 5]。
    *   其他作物：$g_{j,t}(\omega) \sim U(-0.05, 0.05)$[cite: 1, 2, 3, 5]。
    *   累积公式：$D_{j,s,t}(\omega) = D_{j,s,2023} \cdot \prod_{\tau=2024}^t (1 + g_{j,\tau}(\omega))$[cite: 3, 5]。
2.  **种植成本 $C_{i,j,s,t}(\omega)$**：
    *   年均增长率 $g_c \sim N(0.05, 0.01^2)$[cite: 1, 2, 3, 5]。
    *   累积公式：$C_{i,j,s,t}(\omega) = C_{i,j,s,2023} \cdot \prod_{\tau=2024}^t (1 + g_{c,\tau}(\omega))$[cite: 3, 5]。
3.  **销售单价 $P_{j,k(i),s,t}(\omega)$**：
    *   粮食类保持不变；蔬菜类年增 $g_p \sim N(0.05, 0.01^2)$；普通食用菌年降 $d_p \sim U(0.01, 0.05)$；羊肚菌年降固定 $5\%$[cite: 1, 2, 3, 5]。
    *   累积公式：$P_{j,k(i),s,t}(\omega) = P_{j,k(i),s,2023} \cdot \prod_{\tau=2024}^t (1 + \text{rate})$（智慧大棚基准价格高 20% 的特性自动沿用）[cite: 3, 5]。
4.  **亩产量与灾害机制 $Y_{i,j,s,t}(\omega)$**：
    *   常规波动率 $\xi_{j,t}(\omega) \sim U(-0.10, 0.10)$[cite: 1, 4, 5]。
    *   灾害触发：露天耕地（$i \le 34$）每年有 $10\%$ 的独立概率触发减产，减产幅度 $\theta_t(\omega) \sim U(0.30, 0.40)$；大棚不减产[cite: 4, 5]。
    *   综合亩产：$Y_{i,j,s,t}(\omega) = Y_{i,j,s,2023} \cdot (1 + \xi_{j,t}(\omega)) \cdot (1 - \theta_t(\omega) \cdot \mathbb{I}_{\{\text{露天灾害}\}})$[cite: 2, 4, 5]。

#### 2. SAA-CVaR 数学模型
*   **情景 $\omega$ 下的净利润与损失**：
    $$\Pi_t(x, \omega) = \sum_{s \in S} \sum_{(i,j,s) \in \Omega} \left[ P_{j,k(i),s,t}(\omega) \cdot q_{i,j,s,t}^{\text{norm}}(\omega) + 0.5 P_{j,k(i),s,t}(\omega) \cdot q_{i,j,s,t}^{\text{disc}}(\omega) - C_{i,j,s,t}(\omega) \cdot x_{i,j,s,t} \right]$$[cite: 3, 5]
    $$\operatorname{Loss}_t(x, \omega) = -\Pi_t(x, \omega)$$[cite: 3, 5]

*   **CVaR 线性化构造（置信水平 $\alpha = 0.95$）**：
    $$\operatorname{CVaR}_{0.95}(\operatorname{Loss}_t) = \eta_t + \frac{1}{(1 - 0.95) K} \sum_{\omega=1}^K v_t(\omega)$$[cite: 3, 5]
    $$v_t(\omega) \ge \operatorname{Loss}_t(x, \omega) - \eta_t, \quad v_t(\omega) \ge 0, \quad \forall \omega \in \mathcal{W}$$[cite: 3, 5]

*   **目标函数**：
    $$\max \sum_{t \in T} \left( \frac{1}{K} \sum_{\omega=1}^K \Pi_t(x, \omega) - \lambda \cdot \operatorname{CVaR}_{0.95}(\operatorname{Loss}_t) \right)$$[cite: 3, 5]
    （基准取 $\lambda = 0.1$，并在灵敏度分析中测试 $\lambda \in \{0, 0.1, 0.5\}$）[cite: 3, 5]。

*   **约束条件**：
    决策变量 $x, u$ 满足问题 1 的全部刚性物理约束[cite: 2, 3, 5]；各情景下的产销匹配变量满足随机需求上限与随机总产量限制[cite: 3, 5]。

#### 3. 求解与降载策略
*   **情景控制**：选取 $K=50 \sim 100$ 个情景进行样本平均逼近（SAA）[cite: 3, 5]。
*   **计算保底（拓扑固定法）**：若全量求解耗时较长，固定问题 1 最优 0-1 种植拓扑 $u^*$，将模型转为纯连续变量的大规模线性规划，调用 MATLAB `linprog`（内点法）快速求解并填入 `result2.xlsx`[cite: 1, 3, 5]。
*   **稳定性检验**：对比 $K \in \{30, 50, 100\}$ 下的目标函数均值与方差收敛性曲线[cite: 2, 3, 5]。

### 五、 问题 3：融合统计相关性、替代性与互补性的拓展模型

#### 1. 统计分析与业务机制
1.  **正态性检验与相关性分析**：
    *   调用 MATLAB 内置函数 `jbtest` 进行正态性检验[cite: 5]。
    *   调用 `corr(..., 'Type', 'Spearman')` 计算 41 种作物的等级相关系数矩阵，生成相关性热力图[cite: 3, 4, 5]。
2.  **作物功能聚类（K-means）**：
    *   选取“预期销量、均价、成本、价格波动区间” 4 个特征维度，调用 MATLAB 内置 `kmeans` 将作物划分为 4 个主要功能组（大宗粮食、普通蔬果、高价值菌类、特种敏感作物）[cite: 3, 5]。
3.  **市场替代效应机制（需求端拓展）**：
    *   同类且呈现显著负相关（$\rho_{j_1, j_2} \le -0.4$）的作物对构成替代集 $\text{Sub}(j)$[cite: 3, 4, 5]。当替代作物 $m$ 发生减产（即全村需求未完全满足）时，未满足的市场需求按转移系数 $\theta_{m,j}$ 线性增加作物 $j$ 的全村销售上限[cite: 2, 3, 5]：
        $$\tilde{D}_{j,s,t}(\omega) = D_{j,s,t}(\omega) + \sum_{m \in \text{Sub}(j)} \theta_{m,j} \cdot \max\left(0, D_{m,s,t}(\omega) - \sum_{i} Y_{i,m,s,t}(\omega) x_{i,m,s,t}\right)$$[cite: 2, 3, 5]
        （通过引入非负松弛变量保持模型完全线性化）[cite: 2, 3, 5]。
4.  **生态互补折减机制（成本端协同）**：
    *   若地块前一茬种植过豆类，后茬作物的单位种植成本获得常数比例的折减 $\varphi \in (0.85, 0.95)$[cite: 2, 3, 5]：
        $$\tilde{C}_{i,j,s,t}(\omega) = C_{i,j,s,t}(\omega) \cdot \left(1 - \Delta c \cdot \sum_{j_{\text{bean}} \in J_{\text{bean}}} u_{i,j_{\text{bean}},s,t-1}\right)$$[cite: 2, 3, 5]

#### 2. 模型求解与横向对比框架
*   **模型求解**：将更新后的需求上限 $\tilde{D}$ 与折减成本 $\tilde{C}$ 代入问题 2 的 SAA-CVaR 模型中，利用 MATLAB 进行线性规划求解[cite: 2, 3, 5]。
*   **三问多维度对比设计**：
    1.  **经济收益对比**：对比三问的 7 年总利润期望值、总销售额与总成本[cite: 3, 4, 5]。
    2.  **风险控制对比**：对比不同策略下的利润标准差与 95% CVaR 损失[cite: 2, 3, 5]。
    3.  **种植结构对比**：对比粮食、蔬菜、食用菌三大类的种植面积占比演变，说明替代机制如何提升土地产出弹性[cite: 3, 4, 5]。

### 六、 灵敏度分析与模型评价

#### 1. 灵敏度分析设计
*   **风险厌恶系数 $\lambda$ 灵敏度**：取 $\lambda \in [0, 0.5]$，绘制“期望收益 - CVaR 损失”的权衡曲线（Pareto 前沿）[cite: 3, 5]。
*   **灾害概率 $p_{\text{dis}}$ 敏感性测试**：调整灾害概率（$5\% \sim 20\%$），观察露天作物向大棚种植转移的决策倾向[cite: 2, 4, 5]。
*   **最小种植比例 $\delta$ 扰动检验**：测试 $\delta \in [0.05, 0.15]$ 对耕地利用率与总利润的影响[cite: 2, 3, 5]。

#### 2. 模型优缺点评价
*   **优点**：
    1.  **全线性化表述**：所有业务逻辑均转化为标准线性不等式，兼顾全局最优性与求解效率[cite: 2, 3, 5]。
    2.  **原生环境适配**：完全采用 MATLAB 内置函数（`intlinprog`, `linprog`, `jbtest`, `corr`, `kmeans`），无外部依赖[cite: 5]。
    3.  **业务闭环严密**：通过 SAA 处理波动、CVaR 控制尾部风险，参数物理意义清晰[cite: 3, 5]。
*   **缺点与局限**：
    1.  环境随机因子的生成假设了相互独立性，未引入极端天气的跨年度持续性效应[cite: 2, 5]。
    2.  各作物的灾害减产率设定为均一区间，未区分不同作物具体的耐旱或抗涝生理特性[cite: 2, 4, 5]。
