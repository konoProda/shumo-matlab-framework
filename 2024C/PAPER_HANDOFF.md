## 2. 建模概述

### 2.1 模型假设（论文"模型假设"节直接可用）

1. **基准供需平衡**：2023 年各作物各季实际总产量 = 2024~2030 基准预期销售量 D_{j,s}；
2. **多维查表**：亩产/成本/单价按（作物, 地块类型, 季次）查 2023 统计表；单价取区间均值；智慧大棚比其余地块高约 20% 的溢价按类型自动体现（口径 B）；
3. **数据平补**：统计表缺失的"智慧大棚第一季"蔬菜亩产/成本，用普通大棚第一季同作物数据平补；
4. **两阶段决策**：种植面积 x 与 0-1 种植指示 u 为第一阶段决策；产销匹配量（正常价 q^norm / 半价 q^disc）为随机环境展开后的第二阶段决策；
5. **灾害作用范围**：干旱/暴雨等仅作用于露天耕地（大棚有环境调控），露天每地块每年 10% 独立概率触发，减产率每地块独立 U(30%,40%)。

### 2.2 符号体系（核心）

- T={2024,…,2030}；i∈I（54 地块，1~34 露天 / 35~50 普通大棚 / 51~54 智慧大棚）；j∈J（41 作物，豆类 J_bean={1,2,3,4,5,17,18,19}）；s∈{1,2}（季次，单季记 s=1）；Ω：适宜种植三元组（共 1062 个）；
- 决策变量：x_{i,j,s,t}≥0 种植面积（亩）；u_{i,j,s,t}∈{0,1} 是否种植；q^norm_{i,j,s,t}、q^disc_{i,j,s,t}≥0 按地块的正常价/半价销量（斤）；
- 参数：A_i 地块面积；Y/C/P_{j,k(i),s} 亩产/成本/单价（按类型查表）；D_{j,s} 预期销售量；δ=0.10 最小种植比例；N_j^max 分散度上限（粮食类 4 / 水稻 3 / 蔬菜瓜果 8 / 食用菌 6）；u^2023_{i,j,s} 2023 种植锚点；
- 随机情景：ω∈W，K=50（检验用 K=30/100 之一），p_ω=1/K。

### 2.3 问题一：确定性多周期 MILP

- **目标**（max 七年总利润 W）：
  W = Σ_t Σ_s Σ_Ω [ P_{j,k(i),s}·q^norm + γ·P·q^disc − C_{i,j,s}·x ]；
  情况(1) 滞销：γ=0 且 q^disc≡0（超产无收入、全额计成本）；情况(2) 半价：γ=0.5。
- **约束 9 组**：
  C1-1 单地块产量 Q=Y·x（代入消元）；C1-2 全村需求上限 Σ_i q^norm ≤ D_{j,s}；C1-3 单地块产销 q^norm+q^disc ≤ Q；C1-4 面积上限 Σ_j x ≤ A_i；C1-5 最小比例 δA_i u ≤ x ≤ A_i u；C1-6 连作禁止三式（跨年同季含 2023 锚点 / 年内跨季 i∈27..54 / 智慧大棚跨年跨季）；C1-7 豆类轮作：窗口 t−2..t 内 Σu_bean ≥ 1（t∈{2025,…,2030}，B1 修正）；C1-8 集中度 Σ_i u ≤ N_j^max。
- **求解**：MATLAB intlinprog（分支割平面），稀疏装配，两情形分别求解，回填 result1_1 / result1_2。

### 2.4 问题二：两阶段随机规划（SAA + CVaR）

- **随机参数**（逐年独立抽样、复利累积）：
  - 需求增长率：小麦/玉米 g~U(5%,10%)，其他 g~U(−5%,5%)，D_t = D_2023·Π(1+g_τ)；
  - 种植成本：g_c~N(5%,1%²) 全村统一逐年复利；
  - 销售单价：粮食类不变；蔬菜 g_p~N(5%,1%²)；普通食用菌年降 U(1%,5%)；羊肚菌固定 −5%/年；自 2023 价复利（智慧大棚 +20% 基准自动沿用）；
  - 亩产量：常规波动 ξ~U(−10%,10%) 按作物逐年；露天灾害（假设 5）。
- **CVaR 线性化**（α=0.95，λ=0.1 基准）：CVaR_t = η_t + 1/((1−α)K)·Σ_ω v_t(ω)，v ≥ Loss−η，v≥0，Loss = −Π；
- **目标**：max Σ_t [ (1/K)Σ_ω Π_t(ω) − λ·CVaR_t ]；
- **求解策略**：主路径为**拓扑固定法**——沿用 Q1 半价情形的 0-1 拓扑 u*，模型退化为纯线性规划（76 万变量/42 万约束，linprog 内点/对偶单纯形），**exit=1 取得该拓扑下全局最优**；另留全量 MILP 尝试路径（K≤30）。K∈{30,50} 一致性验证通过（相对差 <5%）。

### 2.5 问题三：统计相关性 + 替代/互补拓展

- **统计分析**：jbtest 正态性检验；Spearman 相关矩阵（41×41，市场相关性口径）；K-means 聚类（4 类：大宗粮食/普通蔬果/高价值菌类/特种敏感作物，特征=预期销量/均价/成本/价格波动区间，标准化后聚类）。
- **替代效应（需求端）**：同簇且 ρ≤−0.4 的作物对构成替代集 Sub(j)；需求转移系数 θ=|ρ|（B7）；需求上限修正为直接线性化形式：Σ_i qn_j + Σ_{m∈Sub(j)} θ_{m,j}·Σ_i qn_m ≤ D_j + Σ_m θ_{m,j}·D_m。
- **互补效应（成本端）**：前茬豆类根瘤菌固氮 → 后茬作物单位成本折减 φ=0.90（Δc=0.10，B7）；前茬按时间相邻上一季判定（B6：t 年第一季←(t−1)年第二季，t 年第二季←t 年第一季，单季地块←上年第一季，2024 年用 2023 锚点）；u 拓扑固定后折减为常数系数，保持全线性。
- **求解**：将修正后的需求上限与折减成本代入问题二 SAA-CVaR 框架，拓扑固定 LP 求解。

## 7. 论文表述要点与诚实口径（务必遵守）

1. **Q1 滞销的表述**：intlinprog 在 900 秒时限内得到可行解（3,552 万元），未证明全局最优（跨求解配置利润区间 3,552~4,008 万）；随后固定该 0-1 拓扑，纯 LP 证明**该拓扑下全局最优**（exit=1）。论文建议表述为"分支割平面法时限内可行解 + 拓扑固定线性规划精化"，不得声称"全局最优"。
2. **Q2/Q3 的表述**：主路径为"两阶段随机规划 + 样本平均逼近（K=50）+ CVaR 风险度量"；0-1 种植拓扑沿用问题一最优拓扑（建模文档明示的"计算保底（拓扑固定法）"），产销变量按情景优化——论文按此口径描述即可，求解器均为 exit=1。
3. **数字同源**：所有数字必须与本队运行产物一致（本表即唯一来源）；不得引用三篇范文数字（口径互不可比：范文1 半价 8,582 万、范文3 半价 3,492 万，量级差异即口径差异所致）。
4. **CVaR 为负的解释**：负 CVaR = 最差 5% 情景平均仍盈利，可用"尾部风险损失为负/尾部情景保持盈利"表述。
5. **求解器非确定性**（答辩准备）：intlinprog 同配置跨运行 incumbent 有波动，论文以稳定性检验（3 配置 × 2 情形）数据作为稳健性论据（半价稳定 0.03%；滞销区间如实给出）。
6. **附录代码节选建议**：主程序参数段 + func_q1_milp 的约束装配段（C1-5~C1-8 连作/轮作部分）+ func_q2_saa 的 CVaR 线性化段——三段最能体现模型落地；避免贴完整代码。
