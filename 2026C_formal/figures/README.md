# figures/ 目录说明

论文用图。**每张图一个自包含文件夹**，只保留三件：

```
figures/问题X/<NN 图名>/
├── plot_*.m              绘图脚本（只读 data.csv，不做计算）
├── data.csv              本图用到的全部数字
└── 问题X <图名>.png       ← 人工修证后的定稿，写进论文的就是它
```

## ⚠️ 重跑脚本会覆盖定稿

`plot_*.m` 的输出文件名与定稿**同名**——重新运行脚本会直接覆盖人工修证的图。

- 定稿另有两份副本：论文用 `paper/figures/`、交付用 `deliver/图件/`，被覆盖了从这两处取回即可；
- 确实要重画：先备份该文件夹的 PNG，再跑脚本，最后比对新旧；
- 只是想看图里的数字，直接读 `data.csv`，不必跑脚本。

## 目录约定

| 位置 | 内容 | 引用吗 |
|---|---|---|
| `问题X/<NN 图名>/` | **入选图件**（10 张），均经人工修证 | ✅ 论文用 |
| `_未入选_勿引用/` | 未入选的 4 张（问题二 04/05/06、问题四 02）；图不配，但问题二完美信息基准、问题四峰谷时刻命中率两个数字仍以这里各图的 `data.csv` 为出处 | ⚠️ 只引数、不引图 |

历次口径的图件（`_旧版`、`_旧口径`、`_初版11张`）与 6 张裁定删除的图归档，
已在 2026-09-14 收官清理中移除；取回方式见 `outputs/历史日志/清理记录_20260914.txt`。

**一切以 `_` 开头的目录都不进交付、不写论文**（`scripts/pack_figures.py` 与本条一致）。

## 取图与引用

图里的每个数字都能在**同目录 `data.csv`** 里找到，逐值可溯源。
每张图对应的建模依据、论文位置、口径提醒，见项目根目录的 [`FIGURES_GUIDE.md`](../FIGURES_GUIDE.md)。
