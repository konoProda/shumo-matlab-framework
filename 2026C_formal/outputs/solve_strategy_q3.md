## 1. 规模估算

### 1.1 阶段 0（0:00，全年视野滚动）——每天 1 次，共 334 次

| 项 | 数值 |
|---|---|
| 第 d 天求解槽数 | nS = (D - d + 1) × 144，最大 **48096**（第 1 天），最小 144（第 334 天） |
| 决策变量 | 9 × nS ≤ **432864**（连续，**无二值**——阶段 0 不含 Δ 与互斥二元） |
| 等式约束 | 4 × nS ≤ **192384** 行 |
| 不等式约束 | 0 行（`use_bin = false`） |
| 非零元 | ≈ 12 × nS ≈ **5.8×10⁵** |
| 同规模先例 | **问题二年视野滚动（`func_roll_q2`）为同一装配器、同一规模**，实测 365 天耗时 **7.2 min**（≈1.2 s/天，含 LP + 预测 + 执行层） |

### 1.2 阶段 1~3（当天剩余时段）——每天 3 次，共 1002 次

| 阶段 | 槽数 nS | 变量 12×nS | 其中二值 | 等式 5×nS | 不等式 2×nS |
|---|---|---|---|---|---|
| 1（6:00） | 108 | 1296 | 108 | 540 | 216 |
| 2（12:00） | 72 | 864 | 72 | 360 | 144 |
| 3（18:00） | 36 | 432 | 36 | 180 | 72 |

- 与问题一逐日模型（144 槽 / 1440 变量 / 144 二值 / 实测 ≈0.35 s）**同量级或更小**。
- 预计单次 0.1~0.35 s → 334 天 × 3 次 ≈ **2~4 min**。

```
334 × [ 1 次全年视野 LP（≈1.2 s） + 3 次短 MILP（≈0.1~0.35 s） ] ≈ 10~13 min
```

## 3. 求解策略

### 3.1 阶段 0 → **LP 松弛 + 互斥性校验**（延续问题二主路线）

- 理由：48096 个二值远超 `intlinprog` 边界（>7000 即风险极高）。
- 等价性依据：问题二在**同一装配器、同一规模**下实测"计划解同槽同时充放槽数 = **0 / 48096**"
  （连续松弛的最优解天然满足互斥）。问题三阶段 0 的目标函数与问题二阶段 0 **完全相同**
  （无 Δ 项），故该结论可直接继承，且**仍逐日复核**：
  `out.mutex(d) = Σ min(C,D) > 1e-6` 的槽数，全年应为 0。
- 若某天出现非零：不静默接受，记录该天并改对该天单独跑 MILP（144 二值，成本可忽略），
  报告中标注哪些天走了补救路径。

### 3.2 阶段 1~3 → `intlinprog` **精确 MILP**

- 二值 ≤108，精确求解成本可忽略，无需松弛。
- Δ 两块**不需要**二元变量：目标对 Δ⁺、Δ⁻ 的系数均为正（1.5p、0.5p），
  在等式 Δ⁺ − Δ⁻ = G − G^plan 下最优解自动取纯表示（不会同时为正）。
  该性质由测试固化（`Δ⁺·Δ⁻ = 0` 逐槽检查）。

### 3.3 探针阶梯（强制，不可跳过）

| 阶 | 规模 | 目的 |
|---|---|---|
| 1 | 单日四阶段 | 阶段锁定、四阶段拼接口径、Δ 结算恒等式 |
| 2 | 7 天 | 跨日储能传递、调整费用累计、阶段初值取自实际执行 |
| 3 | 30 天 | 耗时外推与内存观测量级 |
| 4 | 全年 | 后台正式运行 |

### 3.4 ⚠ S0~S3 四策略**不能共用同一份 0:00 计划**（实现层面的诚实说明）

编程侧此前在确认单 G5-2 中告知建模手："四种预报使用策略将**共用同一份 0:00 计划**，
只改变后续调整所依据的预报"。**该承诺在实现层面无法字面达成**，原因是一条真实的反馈链：

```
不同策略 → 调整后的最终购电量 G^adj 不同 → 执行层实际充放电不同
        → 当天 24:00 储电量不同 → 次日 0:00 阶段 0 的初始储电量不同
        → 次日 0:00 计划不同
```

- **可共同的部分**：同一天内，四策略的第 0 阶段使用**同一份输入信息**（同一天的负载、
  同一份 0:00 预报、同一初始储电量），故**第 1 天四策略的 0:00 计划完全相同**
  （初值同为 6000 kWh）；此后逐日分化。
- **实现方式**：四次**独立**的全年前向模拟，各自携带自身的储能轨迹。
- **诚实口径（须写入论文）**：策略间比较包含"储能路径反馈"通道，即差异不仅来自
  "是否使用该时刻预报"本身，还包含由当日调整结果传导到次日的二阶效应。
  该二阶效应可在论文中以"第 1 天四策略计划相同、之后逐日分化"说明其性质。

### 3.5 数值稳定性与自洽检验（/test 固化）

| 检验 | 判据 |
|---|---|
| 确定性算法重复性 | 同一输入两次求解**完全一致**（相对标准差 0） |
| 阶段平衡残差 | (1)(2)(3)(4) 逐槽残差 < 1e-9 |
| 执行层恒等式 | \(R=C+V\)（富余）、\(-R=D+H\)（缺口）逐槽 < 1e-9 |
| 费用自洽 | `cost_plan + cost_adj + cost_em = cost`，相对误差 < 1e-9 |
| 互斥性 | 阶段 0 全年同槽同时充放 = 0；阶段 1~3 由 MILP 保证 |
| Δ 纯表示 | \(\Delta^+_t\cdot\Delta^-_t = 0\) 逐槽 |
| 计划层紧急购电 | 阶段 0~3 的最优解中 \(H^L=H^{ch}=0\)（被正常购电严格支配） |
| 插值相位 | 槽 \([h{:}00,h{:}10)\) 恰等于 \(\hat P_h\)；槽 \([h{:}50,(h{+}1){:}00)\) 等于 \(\hat P_h+\frac56(\hat P_{h+1}-\hat P_h)\) |
| 信息无泄漏 | 阶段 k 的输入最晚数据时刻 ≤ τ_k（预报按发布时刻取；远端起于次日） |
| 储能边界 | \(1200 \le E \le 10800\) 逐槽；日末值 = 次日初值 |
