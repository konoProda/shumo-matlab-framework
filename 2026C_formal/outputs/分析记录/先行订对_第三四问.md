## 二、第三问（第二版）订对要点

**模型理解**：以问题二终稿为母模型，把当天近端 24 h 的光伏中心预测**换成附件3 最新预报**，
在 0/6/12/18 用最新预报重建情景并重解，**只改尚未执行**的购电计划 `A^s`，
最终生效计划 `B` 按时间片拼接（`P`→`A^6`→`A^12`→`A^18`），
调整费**统一相对 0:00 原计划结算一次**（`1.5πΔ⁺ − 0.5πΔ⁻`）。

**结构上的漂亮旁证**：0:00 阶段的变量数 = 问题二同配置 **+288 列**（调增/调减辅助量各 144），
而约束行数、整数变量数**逐项完全相同**（20,160 / 8,064 / 4,032，已用真实装配核对）
⇒ 没有引入新的整数复杂度，问题二跑得通，这里一定跑得通。
（**口径**：这是**程序装配实现**的性质，不是数学模型本身的性质——数学上确实新增了
`A − P = Δ⁺ − Δ⁻` 这组关系，只是装配时复用了原矩阵行。按建模侧意见照此表述。）

**我校验时钉死的两件事**（写进 RETROSPECTIVE R12/R13）：
1. **附件3 索引口径**用三判据独立复核通过——其中"日出配对"是**必要的尖锐判据**：
   光伏曲线平滑，把预报整体平移一小时相关系数反而更高（0.937→0.992），
   只看相关系数会得出错误结论；改用"首个 >50 kW 的小时序号之差"后，267/365 精确对齐、无整体偏移。
2. **附件3 的预报有固有形状偏差**：傍晚比实际早约一小时"熄火"（318/365 天），
   12:00 发布有 −622 kW 系统性偏低。这**正好支撑建模手"不再做确定性校正、把偏差交给随机情景"的决定**。

**已裁的三项**（细节见 `decisions_q3b.md` N1/N6/N7 与确认单 C12~C14）：
1 月只跑 0:00 一次规划（使两问 2 月 1 日储能初值相同，可直接横向对照）；

## 三、第四问订对要点

**模型理解**：问题四 = 问题二/三 **+ 一个价格预测通道 + 一个价格情景维度**。
- `result4-2` = 问题二 + 电价预测 + 电价误差 SAA；
- `result4-3` = 问题三 + 电价预测 + 6/12/18 价格预测更新 + 电价误差 SAA；
- **附件4 的真实电价绝不进入计划阶段**，只用于建模历史、事中结算、事后检验；
- 最终费用一律用**真实价格**重算（紧急购电 `5π^act`、调增 `1.5π^act`、调减违约 `0.5π^act`）。

**数据实测（全部通过）**：
| 项 | 实测 |
|---|---|
| 附件4 完整性 | 365 天 × 144 槽；**非数值 0 个、负值 0 个、零值 0 个**；范围 0.0076~1.7936 |
| 时间口径 | 表头与附件2 **逐列完全相同** ⇒ 同款右移一位，不另立解释 |
| 关键性质 | 附件4 全年均价 **0.7662 = 附件1 固定电价均价**（四位小数相同）⇒ "固定 vs 波动"是**同电价水平下的公平比较** |
| 星期结构 | 周五/周六日均价 0.629 vs 其余 ~0.82 元/kWh（低约 23%） |
| 单日峰谷差 | 均值 1.1049 元/kWh（最小 0.87、最大 1.50）⇒ 储能套利空间充足 |
| 结果模板 | `result4-2` 与 `result2`、`result4-3` 与 `result3` **二进制完全相同** ⇒ 写出代码可直接复用 |

**价格预测实测**：同星期回溯 MAE **0.0480** 元/kWh（相对 6.28%）；
加逐小时偏差校正后 **0.0442**（改善 **10.2%**）；
优于两个朴素基准——附件1 典型日曲线原样复用 0.0991、昨日同时刻 0.0845。
⇒ 建模手选"同周期回溯 + 偏差校正"是对的，且论文有一个现成的**基准对照**可写。

**诚实提示（须写进论文）**：价格**峰谷时刻**预测偏弱——峰/谷时刻精确命中仅 **38.8% / 34.1%**，
1 小时内命中 62.8% / 57.0%；峰谷差预测 MAE 0.0835（实际均值 1.1049）。
**不得声称"精准预测电价峰谷"**；这正是建模文档 §35 要求额外报告峰谷时刻误差的原因。

## 四、我自行裁决的歧义（按授权，不违反题面与建模禁忌）

| 序 | 歧义 | 我的裁决 | 依据 |
|---|---|---|---|
| 1 | **Q4-3 日内"价格预测更新"到底更新什么**（§19.3 说"重新调用模块"，但同星期回溯对当天不依赖当天已实现价格，字面照搬会导致"更新而无所变"，与 §19.1 意图矛盾） | 更新发生在**偏差校正项**：基础预测一天内不变；当天剩余时段的校正量**并入当天已实现时段的同小时残差**；未来日仍只用历史 28 日 | §6.3 原文"偏差校正只能利用决策时刻之前**已经产生**的预测误差"；§19.1"当天已经发生的真实价格已经可以观察到" |
| 2 | **Q4 价格残差库的对齐轴**（§20 写 `e^{π,s}_{r,ℓ}` 但未明说 ℓ 是钟点还是提前量） | 按**提前量**对齐，与问题三附件3 残差库同构 | §20 用的就是提前量符号 ℓ；且只有按提前量对齐才能实现"0:00 误差只和 0:00 预测比、6:00 只和 6:00 比"（§20 原话） |
| 3 | **Q4-3 要不要复制问题三的 S0~S3 四组合** | **不复制**，只跑"四个时点全用"一种 | 题目对"是否需要其他时刻预报"的分析已在问题三完成；问题四的任务是换波动电价后**重算**，其自身对照是 §38 的 P0/P1 |
| 4 | **价格偏差校正是否按日型分组** | **不分组**（同小时 + 全部日型） | 基础预测已是同星期回溯，日型效应已被吸收；再叠加 `周末/工作日` 会把周五错分。**实测**：不分组 0.0442 < 分组 0.0448 |
| 5 | **1 月预热口径**（两问同） | 按已知数据处理、情景退化 `K=1`、只跑 0:00 一次规划 | 与问题二预热同构 ⇒ 2 月 1 日储能初值可跨问对照 |
| 6 | **附件3 残差库的历史日可用性** | 阶段 s 用 `r ≤ d−1` 即已完备，无需按阶段收窄 | 推导：窗口 `[r+s, r+s+24h)` 最早在决策时刻 `d+s` 完全实现 |
| 7 | **调整辅助量要不要整数变量** | 不要 | 数学推导：`Δ⁺`、`Δ⁻` 同时抬高的边际代价为 `+π>0`，最优解自动取单边 |
| 8 | **执行层能否拼接后一次性执行** | 可以，逐槽等价 | 执行层是"给定计划按槽递推"的确定性规则 |

以上 8 项均**未改动建模手的任何方程**，只是把未申明的实现口径补全；其中 1、2 两项属实质歧义，
