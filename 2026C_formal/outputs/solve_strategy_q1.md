## 2. 求解器边界与风险评估

| 项 | 判定 |
|---|---|
| 求解方式 | `intlinprog`（MILP，分支定界 + 割平面） |
| 二值变量数 | 144，处于 intlinprog **舒适区**（经验边界：数百至数千） |
| 预计求解时间 | **秒级 ~ 十秒级**（单次） |
| **风险等级** | **低** |
| 长任务三件套 | **不需要**（不触发后台运行/轮询条件） |
| 单会话铁律 | 无冲突（秒级求解，无需并行） |

**一条有利的结构性质**：由于 \(\eta_c\eta_d=0.81<1\)，同一时段同时充放电会损失能量
（把 \(C_t,D_t\) 同降而保持 \(E_t\) 不变时，购电量 \(G_t\) 同步下降），
故 LP 松弛的根节点解**大概率已接近整数**，分支定界很快收敛。
（此为经验判断，不作为正确性依据——仍需检查 `exitflag` 与 gap。）

## 3. 策略建议

1. **直连求解，不做分解**。问题一为单日、单储能、864 变量的紧凑 MILP，
   无需拓扑固定、降 K、滚动等分解手段。
2. **小规模探针先行**（CLAUDE.md 铁律）：先用 \(T=12\)（2 小时）的缩样数据跑通
   变量装配 → 约束装配 → 求解 → 结果换算全链路，确认矩阵维度与非零位置正确后，
   再上 \(T=144\) 全量。探针脚本存 `scripts/probe_q1_toy.m`（组内产物，不交付）。
3. **求解器参数**：保持 `intlinprog` 默认即可；**必须捕获并记录** `exitflag`、
   `output.gap`、`output.absolutegap`。若 `exitflag` 非 1（非正常收敛），
   需人工介入而非静默接受结果。
4. **显式给界**：`ub` 中 \(V_t\) 的上界逐元素设为 \(PV_t\)，\(G_t\) 上界给
   \(10^5\) kW（充分大但不设 Inf，可帮助预求解器收紧范围）。
5. **结果换算落盘**：求解后立即把 `G_p*dt`、`C_ch*dt`、`D_dis*dt`、`E_soc`
   写 `outputs/q1_solution.csv`，再据此生成 `result1.xlsx`，
   避免"结果只存在于内存、崩溃需重跑"。

## 5. ⚠️ 待补：参考解（/test 的"参考解对比"必选项）

建模文档 §16 给出了残差与约束检查，但**未提供"已知输入-输出对"**。
按 /test 规范，复杂模型的参考解对比为必选项。建议采用以下**两条并行**（互补）：

### 参考解 R1（解析手算，覆盖效率与套利逻辑）

缩样算例：\(T=2\)，\(PV=[0,0]\)，\(L=[600,600]\) kW，
\(\pi=[0.4,0.5]\) 元/kWh，\(\eta_c=\eta_d=0.9\)，\(E_0=E_T=6000\) kWh，\(P_{\max}=5000\) kW。

- **不套利方案**：两槽各购 100 kWh → 费用 \(=100\times0.4+100\times0.5=90.00\) 元
- **套利方案**：槽2 放电 600 kW，则槽1 需充电 \(600/0.81=740.74\) kW；
  槽1 购电 \(600+740.74=1340.74\) kW → 电量 223.46 kWh → 费用 \(=223.46\times0.4=89.38\) 元
- 由于 \(0.4/0.81=0.4938<0.5\)，套利有利 → **最优值 = 89.38 元**

→ 代码在 T=2 缩样下应给出 89.38 元（容差 1e-6）；相对误差判据 < 1e-6。

### 参考解 R2（LP 松弛下界交叉验证，覆盖全量规模）

去掉二值变量与互斥约束，求 LP 松弛最优值 \(Z_{LP}\)，则必有 \(Z_{LP}\le Z_{MILP}\)。
若 \(Z_{MILP}-Z_{LP}\) 在容差内（< 1e-6 或 < 0.01 元），即**同时证明**
MILP 已达全局最优、且互斥约束未被任何时段激活（无同时充放电）。

### 说明

R1 与 R2 均为**编程侧可独立构造**的验证，不依赖建模手额外提供数据。
若建模手另有已知参考解，以建模手提供者为准。**此项不阻塞 /code**，可在 /test 阶段落地。

## 5.5 /prep 阶段预验证结果（2026-09-11 补）

确认单收到后，为核验弃光上界修订（\(V_t\le PV_t\) → \(V_t\le\max(PV_t-L_t,0)\)）的影响，
用附件1 全量 144 槽数据做了一次 LP 预求解（无二元变量，用于快速评估）：

| 检验项 | 结果 |
|---|---|
| 口径A（原 §7.4）最优值 | 35126.948589 元 |
| 口径B（确认单 §6）最优值 | 35126.948589 元 |
| **两口径之差** | **0.0000000000 元 → 修订安全，采用口径B** |
| 最大能量平衡残差 | 1.82e−12 |
| \(\min E\) / \(\max E\) | 1200.00 / 10800.00（均在界内） |
| \(E_{144}\) | 6000.0000（= \(E_0\) ✓） |
| \(\min G\) | 0.00（≥0 ✓，无售电） |
| \(\max\min(C_t,D_t)\) | 0.00 → **无同时充放电**，故该 LP 解已是 MILP 可行解 |
| 全天购电量 / 购电费 | 59482.70 kWh / **35126.95 元** |
| 弃光总量 | 0.00 kWh |

**两点说明**：
1. 由于 LP 解已满足互斥（\(\min(C_t,D_t)=0\) 对所有 t 成立），可推得
   \(Z_{LP}\le Z_{MILP}\le Z_{LP}\)，即 **MILP 最优值 = 35126.95 元**，
   印证了 §2 中"根节点已接近整数、求解会很快"的判断。
2. **此值为 /prep 阶段的预验证结果，不作为最终交付数字**——须由 /code 的
   `intlinprog` 正式求解并由 /test 复核后，方可用于论文（含 `exitflag`/`gap` 记录）。
