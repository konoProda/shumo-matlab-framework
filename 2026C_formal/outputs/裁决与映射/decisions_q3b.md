## 三、模型结构（阶段化两阶段 SAA-MILP）

### 3.1 阶段 s 的模型

在日期 `d`、阶段 `s∈{0,6,12,18}`，记当天剩余时段 `t = s..144`（槽偏移 `sl=6s`，`Tcur=144−sl`）：

**第一阶段（情景无关）**：`A^s_{d,t} ≥ 0`（`t≥s`）；`s=0` 时 `A^0 ≡ P`，无调整。

**第二阶段（逐情景 ω）**：当天剩余时段的 `G^L, G^ch, PV^ch, C, D, E, V, H, W`；未来 6 日的同名变量 + 临时计划 `G^plan,(ω)_{τ,t}`；互斥二元 `u`。

| 编号 | 裁决 |
|---|---|
| **B1** | 当天连接：`G^L + G^ch + W = A^s_{d,t}`（`t≥s`）；未来日连接：`G^L + G^ch + W = G^plan,(ω)_{τ,t}` |
| **B2** | 负荷平衡 `G^L + D + H = L̄`；充电来源 `PV^ch + G^ch = C`；光伏剩余 `PV^ch + V = P̄V`——三条与问题一同构，逐情景 |
| **B3** | 储能递推 `E_t = E_{t−1} + 0.9·C_t·Δt − D_t·Δt/0.9`，逐情景；阶段起点 `E^{(ω)}_{d,sl} = E^act_{d,sl}` 对各情景相同（C8） |
| **B4** | 互斥 `C_t ≤ 5000u_t`、`D_t ≤ 5000(1−u_t)`，`u∈{0,1}`；与问题二完全相同，不加新约束 |
| **B5** | 调整辅助量只对**第一阶段**定义：`A^s_{d,t} − P_{d,t} = Δ⁺_{d,t} − Δ⁻_{d,t}`，`Δ±≥0`。**0:00 阶段不设 `Δ±`**（该阶段没有调整，不采用"保留但不用"的做法，直接不生成）。Q3b 的价格是固定正值，单边性成立 ⇒ **保持连续松弛**；带负价情景的问题四则必须显式互斥（见 `decisions_q4.md` H-2） |
| **B12** | **正常购电计划的物理上界**（订对反馈 H-1）：`0 ≤ P_{d,t}, A^s_{d,t} ≤ U_{d,t}`，`U_{d,t} = max_ω L̄^{(ω)}_{d,t} + 5000`（`L̄` 为该槽净负荷，5000 = 充电功率上限），替代原人工上界 `1e5`。`U` 在当天 0:00 算定后对该日四阶段**冻结**。含义：正常购电最多用于"补负荷 + 最大充电功率"。**价格为正时恒不起作用**（正价下 `W` 无利可图 ⇒ 最优解 `W=0` ⇒ `G^plan = G^L+G^ch ≤ U`），故不改变 Q3b 结果 |
| **B6** | 视野右界 `dEnd = min(D, d+6)`；年末不足则截断（沿用 Q2） |

### 3.2 目标函数

**0:00 阶段**（§26）：

```
min Z_{d,0} = Σ_t π_t P_{d,t} Δt                                ← 第一阶段，不除以 K
            + (1/K) Σ_ω [ Σ_t 5π_t H^{(ω)}_{d,t} Δt
                          + Σ_{τ>d} Σ_t (π_t G^plan,(ω)_{τ,t} + 5π_t H^{(ω)}_{τ,t}) Δt ]
```

| 编号 | 裁决 |
|---|---|
| **B7** | **`s≥6` 阶段**（§27）：`min Z_{d,s} = C^settle,s_d + (1/K)Σ_ω[C^em,s,(ω)_d + C^future,s,(ω)]`，其中 `C^settle,s_d = Σ_{t≥s}[π_tP_{d,t} + 1.5π_tΔ⁺_{d,t} − 0.5π_tΔ⁻_{d,t}]Δt`，`C^em,s,(ω)_d = Σ_{t≥s}5π_tH^{(ω)}_{d,t}Δt` |
| **B8** | 目标中的 `Σ_{t≥s}π_tP_{d,t}Δt` 对当前阶段是常数，**求解时可删**以减小数值量级；**最终费用重算时必须加回**（§27 原文） |
| **B9** | 已执行时段（`t<s`）的费用是沉没成本，**不进入当前阶段优化** |
| **B10** | 未来日（`τ>d`）只按 `π·G^plan` 计价，**不含调整费**——未来日的计划是情景内临时变量，不是提前提交的承诺（§25） |

## 六、调整费用结算

| 编号 | 裁决 |
|---|---|
| **F1** | `B_{d,t}` 为四阶段拼接的最终生效计划（C6）；`Δ⁺_{d,t} − Δ⁻_{d,t} = B_{d,t} − P_{d,t}`，`Δ±≥0` |
| **F2** | 日正常购电 + 调整结算：`C^normal_d = Σ_t [π_tP_{d,t} + 1.5π_tΔ⁺_{d,t} − 0.5π_tΔ⁻_{d,t}]Δt` |
