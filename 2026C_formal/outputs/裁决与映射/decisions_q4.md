## 七、日内价格预测的更新渠道（**正式公式**，经建模侧订对确认）

**问题**：§19.3 要求"在阶段 s 重新调用价格预测模块，信息截止到 (d,s)"，但 D1 的同星期回溯对**当天**的预测只依赖历史同星期日，与当天已实现价格无关——若字面照搬，日内价格预测将"更新"而无所变。

**建模侧订对意见**：方向同意（更新发生在偏差校正项），但**必须给出明确的因果校正公式**；
并特别指出："不能只写'并入同小时残差'，否则早晨误差可能根本不会影响下午预测。"

**正式公式**：设阶段 `s`，当天已实现时段集合 `Ω_s`（槽 `1…6s`，`sl = 6s`），则

```
b_{d,s} = (1/|Ω_s|) · Σ_{t ∈ Ω_s} [ π^act_{d,t} − π̂^{(d,0)}_{d,t} ]      ← 当日水平偏差

π̂^{(d,s)}_{d,t} = π̂^{(d,0)}_{d,t} + b_{d,s}        t > sl（当天尚未执行时段）
π̂^{(d,s)}_{τ,t} = π̂^{(d,0)}_{τ,t}                  τ > d（未来日不变）
```

**性质（逐条对应建模侧的四项要求）**：
1. **只用已实现价格**：`Ω_s` 只含槽 `1…6s`；
2. **不用未来真实价格**：公式中不出现 `t > sl` 的任何实际值；
3. **当天整体偏高/偏低会传导到当天未来的每一个时段**：`b` 是**当日水平**偏差（非逐小时），
   按定义作用于当天**全部尚未执行时段**——6:00 观测到 0:00–6:00 整体偏高，则 14:00/18:00/22:00
   的预测同步上调。**这正是"并入同小时残差"做不到的**（那种写法下早晨误差只落在 1–6 时，
   对未来时段零影响）；
4. **可复现可检验**：只依赖已实现价格与 0:00 中心预测，见 T14/T15。

**未来日不传导的理由**：未来日的价格中心预测在次日 0:00 会被完全重建（§31"预测可跨日用于估值，
正式计划每天重新建立"）。跨日传导的强度缺乏数据依据，引入衰减系数等于新增一个无依据的自由参数，
故不做。**若建模侧希望跨日传导，请给出衰减系数的取值依据，编程侧再补。**

**后果**：Q4-3 的阶段间价格中心预测会真的变化（当天剩余时段），四阶段不退化为同一模型；
且变化只依赖已实现价格，不构成未来信息泄漏。

## 十二、订对结论

1. **模型可落地**：问题四 = 问题二/三 + 一个价格预测通道 + 一个价格情景维度，**不增加约束与整数复杂度**（只是把确定的价格系数换成情景相关系数）；
2. **数据无雷**：附件4 完整、无非数值、无负价、与附件2 同时间口径；均值恰等于附件1 固定电价均值（0.7662），使"固定 vs 波动"的比较是**同电价水平下的公平比较**；
3. **模板零成本**：`result4-2/4-3` 与 `result2/3` 二进制相同，写出代码可直接复用；
4. **需警惕**：日内价格预测的"更新渠道"是本轮唯一实质歧义，已按 §6.3/§19.1 的口径裁决为"偏差校正项日内刷新"（N4），若建模手另有设想应在论文口径说明中提示；
5. **诚实提示**：价格峰谷时刻的预测精度有限（命中率约 1/3），论文不得声称"精准预测电价峰谷"。
