## 三、两层模型结构

### 3.1 第一层：理想信息确定性 MILP（方案文档 §4）

| 编号 | 裁决 |
|---|---|
| **B1** | 每天 0:00 已知**当天**完整真实负荷与光伏；沿用问题一显式分流 MILP，加紧急购电 `H`（**仅一个 H，只供负荷**，不再拆 `H^L/H^ch`） |
| **B2** | 负荷平衡 `G^L + D + H = L̄`；充电来源 `PV^ch + G^ch = C`；光伏剩余 `PV^ch + V = PV̄` |
| **B3** | 目标 `min Σ π(G^L+G^ch)Δt + 5πHΔt`；理论上 **H ≡ 0**，若不为 0 优先查实现/约束/价格口径 |
| **B4** | 实现上复用现有 `func_build_q2`（其 `H^ch` 在 5 倍价与无上限 `G^ch` 下恒为 0，等价于单 H），并在测试中断言 `H^ch ≡ 0` |

### 3.2 第二层：7 日滚动 SAA 两阶段随机 MILP（方案文档 §5~§13）

| 编号 | 裁决 |
|---|---|
| **C5** | 滚动视野 **R=7 天**：每天 d 的 0:00 求解 `d..d+6`，年末不足则截断至 12-31 |
| **C6** | **第一阶段变量只有 `G^plan_{d,t}`**（当天向外部电网提交的计划购电功率），**对所有情景完全相同**；代码中禁止出现按情景索引的当日计划变量 |
| **C7** | **第二阶段变量**逐情景 ω：`G^L, G^ch, PV^ch, C, D, E, V, u, H`；另加 **`W^(ω) ≥ 0`**（已计划购买但未被实际利用的正常购电） |
| **C8** | **未来 2~7 天的临时计划变量** `G^plan,(ω)_{τ,t}`（τ=d+1..d+6）：可随情景变化、不是今天真正提交的未来计划、只用于估计 continuation cost |
| **C9** | **连接约束**：`G^L + G^ch + W = G^plan`（当日用第一阶段的 `G^plan_{d,t}`；未来日用该情景的 `G^plan,(ω)_{τ,t}`）。计划购电即使未用完也**按完整计划量计费**，不允许售回外网 |
| **C10** | **情景物理约束**：情景内 144 槽的分流辅助量由该情景的负荷/光伏算出；SOC 递推、上下界、功率限制、互斥同 §11；**滚动起点 `E^(ω)_{d,0} = E^act_{d,0}` 对所有情景相同** |
| **C11** | **目标**：`min Z_d = C_d^first + (1/K)Σ_ω Q_d^(ω)`，其中 `C_d^first = Σ_t π_t G^plan_{d,t} Δt` 不除以 K；`Q^(ω)` 含当日 `5πH` 与未来日的 `π G^plan,(ω) + 5π H` |
| **C12** | 情景只执行**当天**的 `G^plan_{d,t}`；次日重新预测、重新生成情景并重求解 |

## 八、实现优先级（方案文档 §20）

复用问题一显式分流 MILP → 理想层加 H → 验证第一层 H=0 → 加当天 `G^plan` → 加 W → 加 K=4 情景 → **先跑 R=1 → 再 R=3 → 最后 R=7** → K=8 稳定性。
**不要一开始直接搭全年大模型。**
