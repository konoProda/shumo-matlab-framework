## 3. 目标函数

| 公式编号 | 数学符号 | 含义 | 归属 | 代码变量名 |
|---|---|---|---|---|
| (OBJ) | \(\min C = C_{plan} + C_{adj} + C_{em}\) | 全天总购电费用最小 | 目标 | `out.cost` |
| (OBJ-1) | \(C_{plan} = \sum_t p_t \min(Q^{plan}_t, Q^{adj}_t)\Delta t\) | 计划购电费 | 目标·项 1 | `out.cost_plan` |
| (OBJ-2) | \(C_{adj} = \sum_t (0.5p_t\Delta^-_t + 1.5p_t\Delta^+_t)\Delta t\) | 调整相关费用 | 目标·项 2 | `out.cost_adj` |
| (OBJ-3) | \(C_{em} = \sum_t 5 p_t R_t \Delta t\) | 紧急购电费 | 目标·项 3 | `out.cost_em` |
|    | \(p_t\) | 交易时刻电价（元/kWh） | 参数 | `price_v(t)` |
|    | `0.5 / 1.5 / 5` | 违约 / 超发 / 紧急电价倍数 | 参数 | `0.5`, `1.5`, `prm.kappa_em` |

**实现要点（差额结算，C1 = A）**

对单时段，费用关于调整后购电量 \(Q^{adj}\) 是如下**凸分段线性**函数（连续、两端斜率不同）：

```
Q^adj ≤ Q^plan ：  p·Q^adj + 0.5p·(Q^plan − Q^adj)     → 边际价 0.5p
Q^adj ≥ Q^plan ：  p·Q^plan + 1.5p·(Q^adj − Q^plan)     → 边际价 1.5p
```

- 优化层用两个非负变量 \(\Delta^\pm\) + 一条等式 (9) 实现；因两侧系数均为正，
  最优解自动取"纯表示"（不会同时出现 Δ⁺>0 且 Δ⁻>0），**无需二元变量**。
- 阶段 0 **不设 Δ 变量**（该阶段产出的就是计划本身，Δ ≡ 0），其目标即问题一/二的形式。

## 4. 约束条件（逐条编号，均为每个阶段 k 的区间内逐槽）

| 编号 | 约束 | 类型 | 归属公式 | 代码位置（func_build_q3） |
|---|---|---|---|---|
| (1) | \(G^L_{t,k} + D_{t,k} = \bar L_{t,k}\) | 等式 | 负荷平衡 | `Aeq` 行块 1 |
| (2) | \(PV^{ch}_{t,k} + V_{t,k} = \overline{PV}_{t,k}\) | 等式 | 剩余光伏分配 | `Aeq` 行块 3（beq = PVbar） |
| (3) | \(PV^{ch}_{t,k} + G^{ch}_{t,k} - C_{t,k} = 0\) | 等式 | 充电来源平衡 | `Aeq` 行块 2（beq = 0） |
| (4) | \(E_{t,k} - E_{t-1,k} - \eta_c\Delta t\,C_{t,k} + \frac{\Delta t}{\eta_d}D_{t,k} = 0\) | 等式 | 储能状态转移 | `Aeq` 行块 4（首槽 beq = E_start） |
| (5) | \(C_{t,k} \le P_{\max}u_{t,k}\)，\(D_{t,k} \le P_{\max}(1-u_{t,k})\) | 不等式 | 充放电互斥 | `A` 行 1..2nS |
| (6) | \(E_{\min}\le E_{t,k}\le E_{\max}\) | 上下界 | 电量边界 | `lb/ub` 的 E 段 |
| (7) | \(0\le C_{t,k},D_{t,k}\le P_{\max}\)；\(0\le V_{t,k}\le\overline{PV}_{t,k}\) | 上下界 | 功率与弃光上界 | `lb/ub` |
| (8) | \(G_{t,k} = G^L_{t,k} + G^{ch}_{t,k}\) | 派生定义 | 总购电 | 不设变量，用取和实现 |
| (9) | \(\Delta^+_{t,k} - \Delta^-_{t,k} = G_{t,k} - G^{plan}_t\) | 等式 | 调整量定义 | `Aeq` 行块 5（**仅阶段 1~3**） |
| (10) | \(\bar L_{t,k} = \max(L_t - \hat{PV}_{t,k}, 0)\) | 辅助量 | 分流 | `aux.Lbar` |
| (11) | \(\overline{PV}_{t,k} = \max(\hat{PV}_{t,k} - L_t, 0)\) | 辅助量 | 分流 | `aux.PVbar` |
| (12) | \(E_{\tau_k,k} = E^{\rm act}_{\tau_k}\) | 等式 | 阶段初值 | 传入 `E_start`（首槽 beq） |
| (13) | 已执行时段锁定：\(t<\tau_k\) 的决策不再变动 | 流程 | 阶段推进 | 主循环只保存 T_k 的解、非 T_k 的列保持已生效值 |
| (14) | \(G^{adj}_t = G_{t,k(t)}\)，\(k(t)=\) 最后一个 \(\tau_k\le t\) 的阶段 | 流程 | 阶段拼接 | `Gadj_v(1:36)=stg0`，`Gadj_v(37:72)=stg1`… |

**公式 (9) 中 \(G^{plan}_t\) 是参数**（当天 0:00 阶段已产出并锁定），不随阶段 k 变化
——这就是"所有调整一律与 0:00 原计划比较"（C3 = A）的实现方式。
