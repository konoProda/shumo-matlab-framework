## 二、求解策略（本轮采用）

| 项 | 决策 | 依据 |
|---|---|---|
| 求解器 | `intlinprog`（分支定界/切割），按方案文档 §14.2 | 建模要求 |
| **LP 热启动** | 先 `linprog` 求松弛解，再作为 `x0` 传给 `intlinprog` | 实测 **4.44 s → 0.93 s（4.8×）**，最优值与间隙不变 |
| LP 松弛是否够用 | **不够**：松弛解有 **199 / 4032** 个小数二元分量，必须走 B&B | 实测 |
| 视野顺序 | 按方案文档 §20：**先 R=1 → 再 R=3 → 最后 R=7**，不先搭全年模型 | 建模要求 |
| 互斥变量 | 按情景-日-槽装配 `u`，仅 `u` 为整数 | §11 |

## 三、运行量与时间预算（按实测外推）

| 运行 | 用途 | 次数×求解 | 预计耗时 |
|---|---|---|---|
| 第一层理想基准（逐日，144 二元/日） | 基准 + 验证 H≡0 | 365 次（很快） | < 5 min |
| 正式：SAA+B3，R=7，K=4 | 交付口径 | 365 × (0.27+0.93) s | **约 9 min** |
| 消融：SAA−B3，R=7，K=4 | 量化 B3 与 SAA 各自贡献 | 同上 | 约 9 min |
| T7：R=1 / R=3 | 视野长度对照 | 365 × 0.7 s / 365 × 0.7 s | 约 5 / 5 min |
| T8：K=8，R=7 | 情景数稳定性 | 365 × (0.55 + ~2) s | 约 15 min |
| 合计 | | | **约 45 min**（单会话顺序） |

## 四、风险预判

| 编号 | 风险 | 判据 / 处置 |
|---|---|---|
| S1 | **二元变量使个别日子求解变慢**——本探针只测了第 60 天，全年不同日可能更慢 | 设 `MaxTime` 上限；若某日 `exitflag ≠ 1`，记录该日并以 LP 松弛解 + 互斥性审计兜底，日志中逐日留痕 |
| S2 | **情景抽样不可复现**——随机抽样若种子管理不当会逐次不同 | C1 固定种子 2026；本轮取"**每日重置** `rng(2026)`"，即每天独立可复现；逐日记录抽中的历史日索引 |
| S3 | **信息泄漏**——情景模板必须只用 `s < d` 的残差 | 抽样库限定为 `ok` 掩码内、索引 `< d` 的日；测试 T2 断言"改决策日之后数据不改变当日计划" |
| S4 | **第一阶段非预见性被破坏**——若误把 `G^plan` 写成按情景索引 | 装配时 `G^plan` 只有一组列；测试 T3 断言全情景共用同一 `G^plan` |
| S5 | **退化路径**：有效残差 < max(K,5) 时须退化为确定性（K=1） | C2；逐日记录退化标记；2 月上旬必然退化（一月无残差） |
| S6 | **一月与首日**：一月按已知、不预测、不进误差库 | 沿用 Q2b 口径；`ok` 掩码自 2025-02-01 起 |
| S7 | **量纲**：`G^plan` 是功率、结果文件填 `G^plan·Δt`；`W` 与 `V` 必须分开 | 测试 T4 逐 (d,τ,t,ω) 查守恒；执行层断言 `V·W` 分流 |
| S8 | **3 GB 内存**：单次 MILP 的稀疏矩阵非零元约 2×10⁵，峰值远低于边界；但 **禁止并发** | 单 MATLAB 会话顺序执行全部配置 |

## 五、结论

**策略可行**：MILP 全部求得全局最优、单次 ≤ 9 s、全年 5 组配置合计约 45 min；
瓶颈不在求解器而在"逐日 365 次"的固有次数，已用 LP 热启动把它压到可接受范围。
最需要防的不是性能而是**口径**：非预见性（S4）、情景因果性（S3）、退化路径（S5）、
`V`/`W` 分流（S7）四项均已给出断言判据。
