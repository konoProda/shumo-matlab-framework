## 二、求解器边界与既有策略（不变部分）

| 项 | 现状 | 本轮是否改动 |
|---|---|---|
| 计划层模型 | 每日 0:00 在剩余视野上求**线性规划**（`func_build_q2` 连续松弛，无二元变量） | 不改结构，只替换预测输入 |
| 单次 LP 规模 | 视野 nH 天 → 变量 9×144×nH（首日 nH=365 时约 47.3 万变量） | 不变 |
| 求解器 | `linprog`（对偶单纯形 / 内点，MATLAB 自选）；实测 365 次全 `exitflag=1` | 不变 |

**内存**：本机 3 GB。单次 LP 的稀疏约束矩阵非零元约 7×10⁵，峰值远低于边界；
**单 MATLAB 会话铁律**继续执行——5 次运行排入**同一个后台会话**顺序执行，不并发。

## 三、校正器的实现策略（新增部分）

### 3.1 残差档案：一次算完，不逐日重算

原始预测档案 X̂⁰(s,t|s) 等价于 `func_forecast_q2` **逐日模式**的第 s 行
（逐日模式取"严格早于 τ"的数据，与"决策日 = 目标日"的地平线模式首行完全一致，
该等价性已由问题二既有测试 T10 覆盖）。故一次性算出 D×T 的档案矩阵供全年复用，
**不**在滚动循环内重复调用预测函数。

### 3.2 逐日校正量：查表而非重新统计

对决策日 d，只需窗口 [d−W, d−1] 内 ≤28 天的残差。实现为对预存档案的切片均值，
每日开销 O(W×T) ≈ 4000 次寻址；相对 7.2 min 的单次 LP 可忽略。

### 3.3 与滚动主循环的接口

`func_roll_q2` 增加**末位可选参数** `cfg`（校正配置）。既有调用方
（`main_q2_roll_corr.m` / `main_q2_roll_plan.m` / `scripts/sens_q2_horizon.m`）
均按 11 个位置参数调用，`cfg` 置于第 12 位 → **既有调用不传即自动关闭校正**，
问题三侧 `func_roll_q3` 不经过 `func_roll_q2`，行为不受影响（§6 要求）。

## 四、风险预判（求解侧）

| 编号 | 风险 | 判据 / 处置 |
|---|---|---|
| S1 | **时间修复与校正收益混淆**——若先跑校正再修时间轴，会把相位修复的 31 万元记到校正头上 | 强制顺序：先出"仅修复"基线，再在其上做 B0~B3（§3 明文要求） |
| S2 | **B0~B3 的一月轨迹不共享**——各方案日末储电量反馈到次日，逐日分化 | 一月校正关闭 → 四方案一月输入完全相同；断言 2/1 日初储电量四者一致（§7.1 要求） |
| S3 | **残差递归污染**——若用校正后残差估计下一日，估计对象会漂移 | 档案一律存**原始**预测残差；测试 T 项断言：校正开关变化不改变档案 |
| S4 | **信息泄漏**——校正量不得引用决策日及其后数据 | 窗口上界断言 `max(窗口日) < d`；复用既有 `used_max` 自检口径 |
| S5 | **夜间凭空光伏**——校正把非负截断后的值抬进夜间 | 断言"原始预报为 0 且历史该小时全为 0 ⇒ 校正后仍为 0"（§4.4 明文） |
| S6 | **多解导致逐位不可复现**——LP 多重最优时同一配置两次运行可能有微小差异 | 验收第 2 条已放宽为"比较费用、可行性及差异原因，不苛求逐位相等"；本机实测同配置两次结果逐位一致（问题三八次重跑无差异），必要时以费用为判据 |
| S7 | **3 GB 内存**——5 次全年运行若并发会超限 | 单会话顺序执行 + 后台运行 + 定时轮询（长任务三件套） |
| S8 | **越界调参**——用四个指定日期或全年费用反调 W/γ/最小样本数 | 初版固定 W=28、最小 5 日、γ=1；不调参、不择优（§7.2 明文） |

## 五、结论

策略可行：**总耗时约 40 min，单会话顺序、内存与求解器均不触边界**；
本轮无新增整数变量、无新增求解器类型，风险集中在"顺序纪律"（S1）与"因果关系纪律"（S3/S4），
两条均已给出强制顺序与断言判据。
