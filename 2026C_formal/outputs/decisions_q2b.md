## 二、偏差校正器（方案文档 §4）

| 编号 | 裁决 | 来源 |
|---|---|---|

| **A14** | **残差由当时发布的原始预测形成**：对已完成历史日 s 记 `e^X(s,t) = Xact(s,t) − X̂⁰(s,t|s)`；正负荷误差 = 原预测低估负荷，负光伏误差 = 原预测高估光伏；净负荷误差 `e^N = e^L − e^PV` | §4.2 |

| **A16** | 校正器初版参数：误差回溯窗口 **W = 最近 28 个已完成自然日**；日类型 **工作日／周末**（不引入节假日数据）；**小时粒度**（同小时 6 个槽共享同一校正量）；**最少 5 个有效历史日**（按日数，不得按槽数替代）；**一月只积累、校正关闭**，**2 月起启用** | §4.3 |
| **A17** | 负荷校正分组：优先"同小时 + 同日类型"；不足 5 日 → 退至"同小时 + 全部日类型"；仍不足 5 日 → **校正量取 0**。光伏校正分组："同小时 + 全部日类型"；不足 5 日 → **取 0**。不叠加"月份×小时×日类型"稀疏分组；月份只做事后诊断 | §4.3 |
| **A18** | 校正量算法：**先算每个历史日该小时 6 个槽的平均误差，再对有效历史日等权平均**得 `b^X(d,h)`；缺失较多的历史小时不进入估计，并记录有效日数 | §4.3 |
| **A19** | 校正公式：`L̂* = max{0, L̂⁰ + γ_L·b^L(d,h(t))}`、`PV̂* = max{0, PV̂⁰ + γ_PV·b^PV(d,h(t))}`；初版 **γ_L = γ_PV = 1**，关闭时取 0 | §4.4 |
| **A20** | **夜间无凭空光伏**：原始光伏预测为 0 且回溯历史该小时光伏也全为 0 时，校正后保持 0；**不人为设定全年固定日出日落时刻** | §4.4 |
| **A21** | 采用**有符号**修正（允许增或减），**不统一上调净负荷**；不得把分时均值校正与"人为增加安全裕量"混为一谈 | §4.4 |

| **A23** | **校正只作用于当前决策日的当日预测**；远期 d>d₀ 继续用原地平线预测。函数保持原决策日/目标日/输出数组接口，校正通过配置显式启用 | §4.5 |
