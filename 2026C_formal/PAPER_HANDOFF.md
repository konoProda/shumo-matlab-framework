# 问题一 · 典型日计划购电策略

## 一、建模概述

### 1.1 问题理解

每天 0:00 制定当天的计划购电策略。条件为：**每天的电价与小区负载相同**，光伏为**一天的预测功率**；微网提供的电能不可低于小区负载；储能设备 0:00 与 24:00 的储电量相同。

由数据核验补充事实：附件1 的电价、负载、光伏三列分别等于附件4、附件2 对应列的**全年逐槽平均值**（逐元素比对相关系数 1.00000），故问题一为**单日确定性优化**，采用"典型日"数据。

### 1.2 建模假设（论文"模型假设"处使用）

| 编号 | 假设 | 出处 |
|---|---|---|
| A1 | 不允许向外部电网售电（题面未给上网电价） | `outputs/decisions_q1.md` A1 |
| A2 | 光伏优先供负载，剩余给储能充电，仍剩余则弃光 | A2 |
| A3 | 弃光无收益、无成本 | A3 |
| A4 | 同一时段不允许储能同时充放电（二元变量严格互斥） | A4 |
| A5 | 0:00 与 24:00 储电量相同，均为 6000 kWh（题面强制） | A5 |
| A6 | 目标为全天购电费用最小；仅计电度费用 | A6 |
| A7 | 充放电效率两侧各取 0.90（往返 0.81）——**题面未明示口径，须在论文说明** | N2 / R3 |

### 1.3 符号与参数

| 符号 | 含义 | 取值/单位 | 出处 |
|---|---|---|---|
| \(T\) | 时段数 | 144（10 分钟/槽） | 附录1 |
| \(\Delta t\) | 时段长度 | 1/6 h | — |
| \(\eta_c,\eta_d\) | 充/放电效率 | 0.90 / 0.90 | 附录1 |
| \(E_0,E_T\) | 初/末储电量 | 6000 / 6000 kWh | 附录1 + 题面 |
| \(E_{\min},E_{\max}\) | 储电量上下限 | 1200 / 10800 kWh | 附录1 |

| \(L_t,PV_t,\pi_t\) | 负载 / 光伏预测 / 电价 | kW / kW / 元·kWh⁻¹ | 附件1 |

### 1.4 模型形式

确定性**混合整数线性规划（MILP）**，目标 (1)，约束 (2)~(8)。完整表达式与代码位置见 `IMPLEMENTATION_REPORT.md` 问题一 §一。

**建模裁决记录**：全部裁决见 `outputs/decisions_q1.md`（A1~A8 建模口径、B1~B8 数据处理、N1~N7 数值索引、R1~R6 风险）。建模手确认结果见 `建模手交接/接收自建模手/问题一_确认结果交接给编程手.md`。
