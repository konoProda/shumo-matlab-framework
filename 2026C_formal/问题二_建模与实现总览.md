## 一、问题二在论文中的定位

### 1.1 题面要求（问题二）

> 每天电价相同，小区负载与光伏发电功率随时间变化；微网提供的电能不可低于小区负载，
> 低于负载需向外网**紧急购电**，电价为交易时刻电价的 **5 倍**；除紧急购电费外，
> 其他时段购电费均按计划购电量计算。**请在每天 0:00 制定微网当天的计划购电策略。**
> 根据附件 1 中的电价和附件 2 中的数据……按表 1、表 2 的格式给出表 3 中指定日期的结果，
> 按表 3 的格式给出紧急购电的结果，保存到 result2.xlsx。

**题面的关键留白**：题面只引用附件 1 的**电价**与附件 2 的**数据**，
**未给定负荷与光伏的预测来源**（附件 3 的光伏预报由问题 3 引入）。
该留白是问题二建模的第一个岔路口。

### 1.2 论文应呈现的三情形结构

| 情形 | 计划来源 | 储能执行 | 定位 |
|---|---|---|---|
| ① 理想（完美信息） | 已知全天真实数据的全年联合最优 | 按计划 | **理想下界**，现实中不可得 |
| ② 无纠偏带预测 | 因果预测 + 全年视野滚动 | 严格照计划 | **消融对照**（去掉物理层） |
| ③ 有纠偏带预测 | 同上 | 负载优先实时响应 | **正式口径** |

三情形现均为"**各自信息集下的全年最优**"，区别只在信息集与执行层，可直接并列比较——
这是本问最值得在论文中强调的结构性优点。

### 1.3 一句话结论（可直接用于摘要）

> 以历史数据构造因果预测、并按"负载优先"的物理层与"低价储电"的经济层组织执行后，
> 报送窗口总费用由理想下界的 1,218.28 万元升至 1,758.49 万元（信息价值 44.34%）；
> 其中**物理层是主要杠杆**（紧急购电量降 32.3%），而计划视野超过一周后不再产生额外收益。
>
> ⚠ **本框三个数字属旧口径（预测一月 + 旧电价相位），已作废**——现行口径与数字见 §11。

## 二、模型最终形态（可直接写进论文）

### 2.1 模型类型

**三层结构**：预测层（因果）→ 计划层（滚动优化的 LP/MILP）→ 执行层（物理层 + 经济层）。

### 2.2 预测层（信息集与口径）

| 项 | 口径 |
|---|---|
| 主预测器 | 同星期滚动均值：\(\hat L_{d,t}=\frac{1}{|\mathcal S_d|}\sum_{\tau\in\mathcal S_d}L^{\text{act}}_{\tau,t}\) |
| 回溯集 | \(\mathcal S_d=\{d-7,d-14,d-21,d-28\}\cap\{\tau\ge1\}\)（\(K=4\)） |
| **地平线模式** | 决策日 \(d_0\) 预测未来第 \(\tau\) 天时，回溯集取**严格早于 \(d_0\)** 的最近 4 个同星期日期 |
| 冷启动 | 截止日为 1 → 附件 1 典型日；同星期历史为空 → 前序已发生日的同时段均值 |
| 因果性 | 预测任何未来日期均不得引用决策日及之后的数据（365 个决策日逐一复核） |

> **第三轮修订（§11.2）**：一月（2025-01-01 ~ 01-31）改为按**已知数据**处理后，
> 上表"冷启动"一行**对计划层不再生效**；预测机制自 2025-02-01 起启用，
> 附件1 典型日仅保留用于填补首日 `[0:00,0:10)` 槽（A45~A49）。

### 2.3 计划层（滚动优化）

第 \(d\) 天 0:00 用截止当日的预测，对**剩余全年**求解一次计划优化，**只执行当天**，次日重解。

- **变量**：每槽 9 组（\(G^L,G^{ch},H^L,H^{ch},PV^{ch},C,D,E,V\)），全年视野 473,040 个
- **目标**：正常购电费 + 5 倍紧急购电费
- **约束**：三条流向平衡 + 储能状态转移 + 变量上下界；视界末储电量自由
- **整数性处理**：二值变量达 52,560 个、超出本机求解边界，故用**连续松弛 + 逐日互斥性校验**
  （实测违反 0/52,560，即松弛解本身即整数最优）

### 2.4 执行层（物理层 + 经济层）

计划购电量 \(G^{\text{plan}}_t\) 一经 0:00 确定即**全天锁定**。储能动作按两层组织，
**物理层是硬优先级、不是可选的纠偏策略**。令 \(R_t=G^{\text{plan}}_t+PV^{\text{act}}_t-L^{\text{act}}_t\)：

- \(R_t\ge0\)：\(D_t=0\)，\(C_t=\min\{R_t,P_{\max},(E_{\max}-E_{t-1})/(\eta_c\Delta t)\}\)，\(V_t=R_t-C_t\)，\(H_t=0\)
- \(R_t<0\)：\(C_t=0\)，\(D_t=\min\{-R_t,P_{\max},\eta_d(E_{t-1}-E_{\min})/\Delta t\}\)，\(H_t=\max\{-R_t-D_t,0\}\)

即"**先保证负载被满足（光伏直供 → 储能放电 → 仍不足才紧急购电），有余量才储电**"。
**消融对照口径**＝去掉物理层、只留经济层。

### 2.5 模型的物理含义（论文"模型建立"的叙述线）

> 微网的运行可分解为两个层次：**物理层**回答"电够不够用"——负载必须优先被满足，
> 储能是快速平衡装置；**经济层**回答"什么时候买、什么时候存"——在物理层允许的余量内，
> 低价时段储电、高价时段放电。计划则回答"买多少"，一经确定不再日内修改，
> 与实际运行的差异由储能与紧急购电吸收。

| T15 视野灵敏度回归 | 2 | H=1 复现逐日口径（相对差 1.10×10⁻⁴）；7 天及以上极差 322 元 |
| **T16 导出层日期-槽号配对** | 3 | 逐槽明细构成完整网格且块状排列；图 03 数据与模型矩阵一致（防 2026-09-12 的行序错位复发） |

### 6.2 整数性（论文"模型检验"可写）

计划层连续松弛解中"同槽同时充放电"的槽数为 **0 / 52,560**，
即松弛解本身就是整数最优解，**计划严格可执行**。

### 6.3 视野灵敏度（论文"灵敏度分析"）

见 §3.4。结论：**视野超过一周后边际收益为零**，原因是预测方法只有周周期性。

### 6.4 分层目标对照（建模手 C3 的附加验证）

逐日各解两次同一视界优化、只换目标系数，两者紧急购电量**均为 0、不同的天数为 0**——
计划层正常购电无上限、紧急购电为 5 倍价，最优解恒不采用紧急购电，故分层与加权不产生分歧。

### 6.5 成因分解与对先前结论的修正

对年视野·带纠偏口径 3,777 个紧急购电时段逐段判定：**电量受限 90.9% 槽 / 98.2% 电量**；
缺口时刻的槽初储电量中位数 1,200 kWh（＝下限）、触底占比 77.4%；
但同日日末储电量均值 7,567 kWh、日内最低值均值 1,269 kWh。

**机制**：年视野计划夜间充电、白天按实际缺口放电，**到傍晚峰时已被抽空**，日末再充回来。
**正确表述是"实际缺口超出预测 → 把储能抽干 → 触底后紧急购电"**——
"储能耗尽"是**结果**而非原因。

### 12.2 两层模型：完整变量与约束

#### 12.2.1 第一层：理想信息确定性 MILP（基准）

每天 0:00 已知**当天**完整真实负荷与光伏（现实中不可得），沿用问题一显式分流 MILP 并加紧急购电。

| 变量 | 含义 | 约束 / 目标 |
|---|---|---|
| `G^L` | 正常购电直供负荷 | 负荷平衡 `G^L + D + H = L̄` |
| `G^ch` | 正常购电用于充电 | 充电来源 `PV^ch + G^ch = C` |
| `PV^ch` | 光伏用于充电 | 光伏剩余 `PV^ch + V = PV̄` |
| `C` / `D` / `E` | 充电功率 / 放电功率 / 时段末储电量 | SOC 递推 `E_t − E_{t−1} − ηc·Δt·C_t + (Δt/ηd)·D_t = 0`；`1200 ≤ E ≤ 10800` |
| `V` | 未消纳光伏（弃光） | `V ≥ 0` |
| `u` | 充放电互斥二值 | `C_t ≤ P_max·u_t`、`D_t ≤ P_max·(1−u_t)` |
| **`H`** | **紧急购电（只供负荷，不拆 `H^L`/`H^ch`）** | 目标 `min Σ π(G^L+G^ch)Δt + 5πHΔt` |

理论第一层 `H ≡ 0`（当天真实数据已知则不会出现缺口），实跑窗口紧急电量 0.0 kWh。

#### 12.2.2 第二层：7 日滚动 SAA 两阶段随机 MILP（现实主模型）

**第一阶段变量（与情景无关）**：`G^plan_{d,t}`——当天向外部电网提交的计划购电功率，
**全部 K 个情景共用同一组 T=144 个值**。

**第二阶段变量（逐情景 ω、逐日 τ）**：

| 变量 | 含义 |
|---|---|
| `G^L` / `G^ch` | 情景内正常购电直供负荷 / 用于充电 |
| `PV^ch` / `V` | 光伏充电 / 未消纳光伏 |
| `C` / `D` / `E` | 充电 / 放电 / 时段末储电量 |
| `H` | 情景内紧急购电 |
| **`W^(ω)`** | **已按计划购买但实际未被利用的正常购电**（照付电费，不可售回） |
| `u` | 充放电互斥二值 |
| `G^plan,(ω)_{τ,t}` | **未来 2~7 天的临时计划**（τ = d+1..d+6）；可随情景变化，不是今天真正提交的未来计划，只用于估计继续运行成本 |

**约束（每个情景-日块共 5 组等式 + 互斥）**：

| 编号 | 约束 | 表达式 |
|---|---|---|
| §11.1 | 负荷平衡 | `G^L + D + H = L̄⁺`，其中 `L̄⁺ = max(L̄ − PV̄, 0)` |
| §11.2 | 充电来源 | `PV^ch + G^ch − C = 0` |
| §11.3 | 光伏剩余 | `PV^ch + V = PV̄⁺`，其中 `PV̄⁺ = max(PV̄ − L̄, 0)` |
| §11.4 | SOC 递推 | `E_t − E_{t−1} − ηc·Δt·C_t + (Δt/ηd)·D_t = 0` |
| §10 | **计划连接** | `G^L + G^ch + W − G^plan = 0`（当日用第一阶段 `G^plan_{d,t}`；未来日用该情景的临时计划） |
| §11.6 | 充放电互斥 | `C_t ≤ P_max·u_t`、`D_t ≤ P_max·(1−u_t)` |

**滚动起点**：`E^(ω)_{d,0} = E^act_{d,0}`，K 个情景从**同一个**实际储电量出发。

**目标函数**：

`min Z_d = Σ_t π_t·G^plan_{d,t}·Δt + (1/K)·Σ_ω [ Σ_t 5π_t·H_{d,t}·Δt + Σ_{τ>d} Σ_t (π_t·G^plan,(ω)_{τ,t} + 5π_t·H_{τ,t})·Δt ]`

第一项（第一阶段，**不除以 K**）是实际要付的电费；第二项是 K 个情景的期望继续运行成本（除以 K）。

**滚动与执行**：每天 d 的 0:00 求解 `d..d+6`（年末不足截断至 12-31），**只执行当天**的 `G^plan_{d,t}`；
次日重新预测、重新生成情景、重新求解。

#### 12.2.3 本轮建模的核心（一句话）

**当天计划购电对所有情景完全相同**——提交计划时还不知道哪个情景会发生。情景差异只能体现为
"同样的计划电量在不同情景里被用掉多少"，用不完的部分记为 `W` 并照付电费。
`outputs/q2c_handback_tables.md` 表 9 给出这一结构的实测代价：**W 合计 1,136,190.3 kWh，占计划购电总量 4.778%**。

### 12.3 执行层优先级规则（当天实际运行）

`G^plan_{d,t}` 一经 0:00 提交即**全天锁定、不可修改**，只允许储能实时响应与紧急购电兜底（E1）。
逐槽按以下优先级分流（E2/E3）：

1. **光伏供负荷**（`PV^L = min(PV, L)`，由输入数据确定，不作决策变量）；
2. **计划购电补负荷**；
3. 仍不足：**先放电，再紧急购电**（紧急购电是最后兜底）；
4. 负荷满足后：**光伏余电优先充储能**；
5. 其次：**用剩余的计划购电充储能**；
6. 仍剩余的光伏记 **`V`**（未消纳光伏），仍剩余的已购电记 **`W`**（已购未用）——**两者必须分开记账**，
   因为前者是零成本的弃光、后者是按计划价照付的电费；
7. **充电不挤占负荷**；**紧急购电不给储能充电**；同一槽 `C > 0` 与 `D > 0` 不得同时成立。

实际储电量按 `E^act_{d,t} = E^act_{d,t−1} + 0.9·C^act·Δt − D^act·Δt/0.9` 递推，跨日
`E^act_{d+1,0} = E^act_{d,T}`（E4）。实测滚动起点 SOC 递推一致性：逐日 E0 与前一实际日末最大差 0.000e+00 kWh（表 9）。

### 12.6 可进论文的四个量化结论

1. **信息集阶梯**：补上"全年联合完美信息 12,227,142.86 元"这一理论下界后，三级台阶为
   12,227,142.86（全年联合完美）→ 12,253,936.65（逐日完美，+26,793.79 = SOC 短视代价）
   → 14,806,890.28 元（滚动 SAA，+2,552,953.63 = 预测不确定性代价）。两者相差约 95 倍（由表 3 两行相除）——
   **瓶颈在预测，不在视野**。
2. **视野的作用机制**：R=1 日末 SOC 均值 1,961.4 kWh（电池几乎常年触底）→ R=3 为 7,045.7 → R=7 为 7,046.0 kWh；
   费用 14,884,621.29 → 14,806,918.29 → 14,806,890.28 元。**视野只需 3 天即可拿到绝大部分价值**。
3. **情景数稳定性**：K=4→8 费用 −1.962%、紧急电量 −14.56%，均在 5% 判据内；
   紧急电量的敏感度约为费用的 7.4 倍（由表 5 两个相对差相除），须一并写明。
4. **B3 的代价与收益不对称**：SAA+B3 比 SAA−B3 贵 135,686.00 元（+0.92%）但紧急电量少 5,048.3 kWh——
   校正换到的是"更少的紧急备电"，不是"更低的费用"，是一个必须如实呈现的权衡。

### 12.8 诚实限定（论文不得越界表述）
