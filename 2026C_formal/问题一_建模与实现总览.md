## 一、问题一在论文中的定位

### 1.1 题面要求（问题一）

每天 0:00 制定当天的计划购电策略，条件为：

1. 每天的电价与小区负载**相同**；
2. 给出光伏发电功率**一天的预测数据**；
3. 微网提供的电能**不可低于**小区负载；
4. 储能设备在 **0:00 与 24:00 的储电量相同**。

要求给出：指定时段的购电量与全天购电量/购电费（论文表 1）；储能充放电量与 0:00/24:00 储电量（论文表 2）。

### 1.2 论文应呈现的三层结构

| 层次 | 内容 | 本文档对应节 |
|---|---|---|
| 数据层 | 附件1 是"典型日"、电价日内波动、光伏正午单峰 | §4.1 |
| 模型层 | 显式分流 MILP（8 变量组、三条流量平衡） | §2 |
| 结果层 | 全天购电费 35126.95 元、零弃光、谷充峰放 | §3 |

### 1.3 一句话结论（可直接用于摘要）

> 在典型日条件下，按"光伏优先供负载、余电优先充电、谷段补购外网电"的策略，
> 微网全天购电费为 **35126.95 元**，较**无储能基准方案**（48052.05 元）降低 **26.90%**，
> 等效完成 1.75 次储能循环，且富余光伏被完全消纳、**全天零弃光**。

> **基准方案口径**：储能不动作（\(C_t=D_t=0\)），购电量 \(=\max(L_t-PV_t,0)\)，
> 购电费 48052.0466 元。降幅与明细见 §6.4。

## 二、模型最终形态（可直接写进论文）

### 2.1 模型类型

**显式分流的确定性混合整数线性规划（MILP）**，变量 \(8T = 1152\)（\(T=144\) 个 10 分钟时段）。

### 2.2 分流辅助量（由输入数据确定，不是决策变量）

\[
PV^L_t=\min(PV_t,L_t),\qquad
\overline L_t=\max(L_t-PV_t,\ 0),\qquad
\overline{PV}_t=\max(PV_t-L_t,\ 0)
\]

- \(PV^L_t\)：光伏直接供负载功率；
- \(\overline L_t\)：光伏供电后仍未满足的负荷功率；
- \(\overline{PV}_t\)：光伏满足负荷后剩余的功率。

> **为何不作决策变量**：若允许优化，求解器会人为减少光伏直供负载、改由外网供负载，
> 从而违反"光伏优先供负载"的调度口径。

### 2.3 决策变量（8 组）

| 变量 | 含义 | 取值范围 |
|---|---|---|
| \(G^L_t\) | 外网**直接供负载**功率 | \(\ge 0\) |
| \(G^{ch}_t\) | 外网**供储能充电**功率 | \(\ge 0\) |
| \(PV^{ch}_t\) | 光伏**供储能充电**功率 | \([0,\overline{PV}_t]\) |
| \(C_t\) | 储能充电功率 | \([0,P_{\max}]\) |
| \(D_t\) | 储能放电功率 | \([0,P_{\max}]\) |
| \(E_t\) | 第 \(t\) 槽**结束**时储电量 | \([E_{\min},E_{\max}]\) |
| \(V_t\) | 弃光功率 | \([0,\overline{PV}_t]\) |
| \(u_t\) | 充放电状态（二元） | \(\{0,1\}\) |

**总购电 \(G_t=G^L_t+G^{ch}_t\) 为派生量**，不设独立变量。

### 2.4 目标函数

\[
\min Z=\sum_{t=1}^{144}\pi_t\,(G^L_t+G^{ch}_t)\,\Delta t
\]

### 2.5 约束条件

| 编号 | 名称 | 表达式 |
|---|---|---|
| (2) | 负荷平衡 | \(G^L_t+D_t=\overline L_t\) |
| (3) | 充电来源平衡 | \(PV^{ch}_t+G^{ch}_t=C_t\) |
| (4) | 光伏剩余平衡 | \(PV^{ch}_t+V_t=\overline{PV}_t\) |
| (5) | 储能状态转移 | \(E_t=E_{t-1}+\eta_c C_t\Delta t-D_t\Delta t/\eta_d\) |
| (6) | 容量与初末 | \(1200\le E_t\le 10800\)；\(E_T=E_0=6000\) |
| (7) | 充放电功率 | \(0\le C_t,D_t\le 5000\) |
| (8) | 充放电互斥 | \(C_t\le P_{\max}u_t\)，\(D_t\le P_{\max}(1-u_t)\) |

**参数**：\(\Delta t=1/6\) h｜\(\eta_c=\eta_d=0.90\)｜\(P_{\max}=5000\) kW｜\(T=144\)

> **两条重要说明（论文如被问及可引用）**：
> 1. **总能量平衡 \(G_t+PV_t+D_t=L_t+C_t+V_t\) 不作为约束**——它可由 (2)(3)(4) 推出，
>    在代码中作为**导出校验量**。这使模型能追踪每一类能源的实际流向。
> 2. 约束 (2) 配合 \(G^L_t\ge0\) 隐含 \(D_t\le\overline L_t\)；
>    约束 (4) 配合 \(PV^{ch}_t\ge0\) 隐含 \(V_t\le\overline{PV}_t\)。
>    这两条正是"放电不超过负荷缺口、弃光不超过光伏剩余"的物理约束，**无需另设不等式**。

### 2.6 模型的物理含义（论文"模型建立"段的叙述线）

\[
\boxed{
\text{光伏优先供给负载}
\rightarrow
\text{光伏剩余供储能充电}
\rightarrow
\text{外网低价时补充充电}
\rightarrow
\text{仍无法消纳则弃光}
}
\]

## 十、术语表

| 术语 | 含义 |
|---|---|
| 典型日 | 附件1 的数据性质（全年逐槽平均值），非某一具体日期 |
| 显式分流 | 把总能量平衡细化为三条流向平衡，使每类能源的去向可追踪 |
| 分流辅助量 | \(PV^L_t,\overline L_t,\overline{PV}_t\)，由输入数据确定，不参与优化 |
| 等效循环次数 | 全天放电量 ÷ 可用容量（10800−1200 = 9600 kWh） |
| 弃光 | 无法被负载与储能消纳的多余光伏，不可售、无收益 |
| LP 松弛下界 | 去掉整数约束后的最优值，是 MILP 最优值的下界，用于夹逼证明最优性 |
| 反算交叉校验 | 由物理量反推分流变量，与模型内取值比对的一致性检验 |
