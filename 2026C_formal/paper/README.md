## 编译

```bash
cd 2026C_formal/paper
latexmk -xelatex main.tex        # 或 latexmk main.tex（latexmkrc 已指定 xelatex）
latexmk -C                       # 清理中间文件
```

**必须用 XeLaTeX**：`ctexart` 在 PDFLaTeX 下会在中文字体处直接报错。

## 三条容易踩的编号约束（改源码前务必先读）

1. **公式编号必须全局连续**。`main.tex` 里把 `\theequation` 显式重定义为 `\arabic{equation}`，
   且**没有**用 `\numberwithin{equation}{section}`。
   一旦改成按节编号，85 个公式会变成 `5.1 … 8.31`，与初稿的 tag 1…85 全部错位。
2. **章节号必须显式重定义** `\thesection/\thesubsection/\thesubsubsection`。
   `titlesec` 的 `\titleformat` 只改**显示标签**，不改 `\thesection` 本身；
   只写 `\titleformat` 会让交叉引用拿到阿拉伯数字，出现"一、…"与"1.1"对不上的错号。
3. **图件用 ASCII 文件名**（`q1_day_plan.png` 等）。原文件名含中文与空格，
   部分 TeX Live 版本下 `\includegraphics` 会 `File not found`。
   原始中文名仍是交付名，见 `../figures/`。

## 首次编译后需人工确认的 7 项

以下问题**无法静态查出**，只有真正编译一次才会暴露：

1. `titlesec` × `ctexart` 的兼容性（`\chinese{section}` 作为 `\thesection` 有无警告）；
2. `\text{中文}` 在数学环境里的字体落位（正文中多处 `\text{…元}`）；
3. `\VerbatimInput` 内中文注释的字体（附录 B 的代码含中文注释与 `……`）；
4. 表格是否溢出：已按最宽内容收窄（`\tabcolsep` 4pt、符号表 `p{}` 列、7 列表 `\resizebox`），仍建议目视确认一次；
5. 浮动体 `[H]` 是否产生孤页（全部表用 `[H]`，图用 `[htbp]`）；
6. 摘要是否**恰好占一页**（`abstract.tex` 末尾有 `\newpage`）；
7. 全文页数是否落在 25–30 页（规范 §二）。

## 首轮编译暴露的两个缺陷（已修）

自检全绿不等于能编译。第一次真编译暴露了两处，都已定位到**生成器**并修掉：

| 报错 | 真因 | 修法 |
|---|---|---|
| `Missing $ inserted` @ `q1.tex:588` | `build_tex.py` 的 `esc_text` 写成 `s.replace('%', r'\%')`，对初稿里**本来就是 `\%`** 的地方又转一次，`\(12.5\\%\)` 里的 `\\` 是数学模式换行命令 | 改为 `re.sub(r'(?<!\\)%', …)` 只转未转义的；同时把 `& _ #` 排除在外——文本与表格单元里含 `\(x_t\)` 这类行内公式，盲转会破坏数学 |
| `Not in outer par mode` @ `q4.tex:739` | `insert_figures.py` 的锚点取在 `\label{tab:12}` 的下一行，而该行仍在 `table` 内，图被塞进浮动体 | 新增 `after-env` 模式：按 `\begin/\end` 配对跳到**整个浮动体之后** |

两条都已加进自检：L2 查行内 `$` 成对，L6 查浮动体套嵌。**都做过反向验证**
（注入缺陷后确认能被抓到），不是"写完就当它会工作"。

> 该自检器整体做过反向验证：注入"手写标题序号 / 裸 `%` / 未闭合环境 / `\numberwithin` /
> `\input` 目标缺失 / 单侧 `$` / 浮动体套嵌"七类缺陷，七类均被对应层抓到。
> 未做反向验证前，它曾因 `strip_comment` 被当成"整篇"调用而在全文第一个 `%` 处截断，
> 导致 L1 只检查了前几行、裸 `%` 完全没查——那版是"永远 PASS 的假检测器"。

**`check_numbers.py`**（36 行核查项，当前 36/36 一致）把正文每个关键数字反查到
`outputs/` 的**字段级出处**，并做双向核对：正向查"出处值是否进了正文"，
反向查"正文里的大额数字是否都有出处"。反向清单当前为 **0**。

编程/论文手做数字一致性核对时，直接看 `number_check.txt`：每行是
`论文处 | 论文数值 | 出处文件 · 字段 | 核查`，逐条打勾即可。

## 表格编号与赛题"表 1/表 2/表 3"的关系

赛题要求"以表 1 的格式给出……"，这里的**表 1/表 2/表 3 是赛题中的表号**，
指的是**格式**，不是要求论文里的表就叫表 1。论文的表格编号由 LaTeX 全篇连续生成。
对应关系在每处引导句里写明（如"按题目表 1 与表 2 要求的格式，将上述结果整理如表 X 与表 Y"），
评审核对时不会混淆。

1. **`symbol.tex` 4 张表的表题错位** —— 转换器按出现顺序发题号，但初稿的
   `\subsection` 顺序与表格顺序不一致，导致“四问共用变量表”顶着“辅助量”的题。
