# 1. 问题二最终拆分思路

问题二不再只给一个口径，而分为两部分。

## 1.1 第一部分：题面数据直接使用的“完美信息基准”

【当前确认口径】在第 \(d\) 天 0:00 制定当天计划时，假定当天完整的实际负载和实际光伏功率均已知：

\[
L^{\mathrm{act}}_{d,t},\qquad PV^{\mathrm{act}}_{d,t},\qquad t=1,\ldots,T.
\]

在该假设下，使用当天真实曲线求解日内最优购电与储能计划，并将日末储能状态传递到下一天。

该部分的作用不是宣称现实中可以预知未来，而是：

1. 给出对题面“直接使用附件 2 数据”的确定性解释；
2. 给出一个**理想信息基准**；
3. 验证当前问题一物理模型扩展到全年后的运行规律；
4. 与第二部分的因果预测策略比较，量化“预知未来信息”的价值。

【逻辑推导】在普通购电没有容量上限、且紧急购电价格为普通电价 5 倍的条件下，该部分的紧急购电量理论上应趋近于 0。出现全 0 不视为程序异常，而视为完美信息口径下的模型性质。

---

## 1.2 第二部分：现实可执行的“预测—计划—实际结算”改进模型

【逻辑推导】每天 0:00 就提前知道当天完整的真实负载和真实光伏明显不符合现实调度逻辑，因此第二部分改为：

\[
\boxed{
\text{历史数据形成当日预测}
\rightarrow
\text{0:00 制定全天计划}
\rightarrow
\text{当天实际数据实现}
\rightarrow
\text{不足部分紧急购电}
}
\]

在第 \(d\) 天 0:00，只允许使用 \(d\) 日之前已经发生的数据构造：

\[
\hat L_{d,t},\qquad \widehat{PV}_{d,t}.
\]

再由【复习清单内】MILP 制定当日计划购电和储能策略。当天结束后，用附件 2 的实际值：

\[
L^{\mathrm{act}}_{d,t},\qquad PV^{\mathrm{act}}_{d,t}
\]

进行实际结算；若计划供电不足，则按题意以 5 倍交易时刻电价紧急购电。

该部分作为问题二的**现实改进主方案**。

# 2. “全年滚动 MILP”的含义——必须统一

【实现约定】本文所谓“全年滚动 MILP”是：

> **从 2025-01-01 起按天顺序滚动，每天 0:00 建立并求解一个 144 槽 MILP，日末储能状态传递到下一天；循环至 2025-12-31。**

即：

\[
\text{Day 1 MILP}
\rightarrow E_{1,T}
\rightarrow
\text{Day 2 MILP}
\rightarrow E_{2,T}
\rightarrow\cdots
\]

不是在 1 月 1 日一次性把全年真实未来数据送入一个 52560 槽模型作为现实执行策略。

如编程侧保留“全年一次性联合优化”，只能命名为：

> **全年完美预见联合基准**

并仅作理论下界/理想对照，不得替代本文的全年逐日滚动策略。

# 3. 时间轴口径——本次按最新确认执行

## 3.1 基本时间尺度

每天划分为：

\[
T=144
\]

个 10 分钟时段，

\[
\Delta t=\frac16\ \mathrm{h}.
\]

## 3.2 数据标签含义

【最新确认口径，覆盖此前旧口径】**时间标签表示对应时段的起始时刻。**

例如：

\[
\boxed{
\text{标签 }0{:}10\text{ 的电价对应时段 }[0{:}10,0{:}20)
}
\]

因此任一标签 \(\tau\) 的数据均解释为：

\[
[\tau,\tau+10\text{ min}).
\]

编程时严禁继续使用“0:10 对应 [0:00,0:10)”的旧解释。

### 时间轴实现要求

1. 必须按实际时间戳建立时段映射，不得只靠行号猜测；
2. 价格、负载、光伏、计划购电、充放电、紧急购电必须使用同一时间槽；
3. 若数据中出现 `0:00+1`，其含义按“次日 0:00”处理，不得错配到前一时段；
4. 回填结果模板前先做一项人工可读校验：检查 `0:10` 行是否确实对应 `0:10-0:20`；
5. 所有按小时/4 小时汇总结果均按上述起始标签口径积分。

# 5. 共用物理模型

## 5.1 光伏优先分流

对给定的一组负荷、光伏输入 \((L_{d,t},PV_{d,t})\)，先计算：

\[
PV^L_{d,t}=\min(PV_{d,t},L_{d,t}),
\]

\[
\overline L_{d,t}=\max(L_{d,t}-PV_{d,t},0),
\]

\[
\overline{PV}_{d,t}=\max(PV_{d,t}-L_{d,t},0).
\]

沿用问题一：光伏优先供负载，剩余光伏优先进入储能，再余部分允许弃光；不允许向外网售电。

## 5.2 负荷平衡

完美信息部分：

\[
G^L_{d,t}+D_{d,t}+H_{d,t}
=
\overline L^{\mathrm{act}}_{d,t}.
\]

其中完美信息条件下 \(H_{d,t}\) 应自然优化为 0。

## 5.3 充电来源平衡

\[
PV^{ch}_{d,t}+G^{ch}_{d,t}=C_{d,t}.
\]

## 5.4 光伏剩余平衡

\[
PV^{ch}_{d,t}+V_{d,t}=\overline{PV}_{d,t}.
\]

## 5.5 储能状态转移

\[
E_{d,t}
=
E_{d,t-1}
+\eta_c C_{d,t}\Delta t
-\frac{D_{d,t}\Delta t}{\eta_d}.
\]

## 5.6 充放电互斥

\[
C_{d,t}\le P_{\max}u_{d,t},
\]

\[
D_{d,t}\le P_{\max}(1-u_{d,t}),
\]

\[
u_{d,t}\in\{0,1\}.
\]

## 5.7 储能边界

\[
1200\le E_{d,t}\le10800.
\]

第一天：

\[
E_{1,0}=6000\ \mathrm{kWh}.
\]

跨日连续：

\[
\boxed{
E_{d+1,0}=E_{d,T}
}
\]

问题二**不强制**每日 \(E_{d,T}=E_{d,0}\)。

【逻辑推导】如果逐日目标导致日末电量频繁落到 1200 kWh，这是滚动短视效应，不能擅自用问题一的“日首=日末”条件抹掉。程序应如实记录，并与完美预见联合基准比较其影响。

# 6. 第一部分：完美信息基准 MILP

## 6.1 日初信息

第 \(d\) 天 0:00 直接使用：

\[
L_{d,t}=L^{\mathrm{act}}_{d,t},\qquad
PV_{d,t}=PV^{\mathrm{act}}_{d,t}.
\]

## 6.2 目标函数

【题面直接信息】紧急购电价格为交易时刻价格的 5 倍，因此当天目标为：

\[
\boxed{
\min Z_d^{\mathrm{PI}}
=
\sum_{t=1}^{T}
\left[
\pi_t(G^L_{d,t}+G^{ch}_{d,t})
+5\pi_t H_{d,t}
\right]\Delta t
}
\]

并满足第 5 节全部约束。

## 6.3 预期性质

在无普通购电容量上限的条件下，因：

\[
5\pi_t>\pi_t,
\]

且全天实际负荷、光伏均已知，所以最优计划会提前覆盖可预见缺口。

因此：

\[
\boxed{H_{d,t}=0}
\]

是合理预期，不得为了让表 3 出现非零值而人为增加不存在的购电功率上限或其他约束。

## 6.4 该部分论文定位

建议名称：

> **完美信息下的全年逐日滚动 MILP 基准**

不得写成“现实可直接执行的最终策略”。

# 7. 第二部分：预测驱动的现实改进 MILP

# 7.1 信息集约束

第 \(d\) 天预测时，只允许使用：

\[
\mathcal I_d
=
\{L^{\mathrm{act}}_{\tau,t},PV^{\mathrm{act}}_{\tau,t}:\tau<d\}.
\]

【实现硬约束】预测第 \(d\) 天时，代码不得读取第 \(d\) 天及之后任何实际负荷或实际光伏数据。

应单独写“信息泄漏测试”验证这一点。

---

# 7.2 主预测方法：同星期滚动均值

【复习清单内】采用“同周期均值”作为主预测方法，避免引入不必要的复杂黑箱。

对第 \(d\) 天，取此前最多 \(K=4\) 个与第 \(d\) 天星期属性相同的日期集合：

\[
\mathcal S_d
=
\{d-7,d-14,d-21,d-28\}\cap\{\tau:\tau\ge1\}.
\]

则：

\[
\boxed{
\hat L_{d,t}
=
\frac{1}{|\mathcal S_d|}
\sum_{\tau\in\mathcal S_d}
L^{\mathrm{act}}_{\tau,t}
}
\]

\[
\boxed{
\widehat{PV}_{d,t}
=
\frac{1}{|\mathcal S_d|}
\sum_{\tau\in\mathcal S_d}
PV^{\mathrm{act}}_{\tau,t}
}
\]

当同星期历史不足时，使用下述冷启动规则。

# 7.4 0:00 计划 MILP

对第 \(d\) 天，将问题一中的 \(L_t,PV_t\) 替换为：

\[
\hat L_{d,t},\qquad \widehat{PV}_{d,t}.
\]

先计算预测口径下：

\[
\widehat{PV^L}_{d,t}
=
\min(\widehat{PV}_{d,t},\hat L_{d,t}),
\]

\[
\widehat{\overline L}_{d,t}
=
\max(\hat L_{d,t}-\widehat{PV}_{d,t},0),
\]

\[
\widehat{\overline{PV}}_{d,t}
=
\max(\widehat{PV}_{d,t}-\hat L_{d,t},0).
\]

以预测数据求解计划变量：

\[
G^{L,plan}_{d,t},
G^{ch,plan}_{d,t},
PV^{ch,plan}_{d,t},
C^{plan}_{d,t},
D^{plan}_{d,t},
E^{plan}_{d,t},
V^{plan}_{d,t},
u^{plan}_{d,t}.
\]

计划总购电：

\[
G^{plan}_{d,t}
=
G^{L,plan}_{d,t}+G^{ch,plan}_{d,t}.
\]

日初计划阶段不使用当天实际数据，因此不把实际紧急购电 \(H^{act}_{d,t}\) 放进日初 MILP 的已知量。

计划目标：

\[
\boxed{
\min Z_d^{plan}
=
\sum_{t=1}^{T}
\pi_tG^{plan}_{d,t}\Delta t
}
\]

其余约束与问题一一致，只是输入替换为预测负荷、预测光伏，日初 SOC 使用前一日实际/结算后的日末 SOC。

# 7.5 实际执行与紧急购电结算

【题面直接信息】正常计划购电按计划量收费，若供能不足则紧急购电，紧急购电价为交易时刻电价的 5 倍。

第二部分中，0:00 求出的：

\[
G^{plan}_{d,t},\quad C^{plan}_{d,t},\quad D^{plan}_{d,t}
\]

作为全天计划，不因当天真实数据事后重算普通购电量。

当天实际实现值为：

\[
L^{act}_{d,t},\qquad PV^{act}_{d,t}.
\]

计划策略在实际数据下对负荷提供的净功率为：

\[
P^{net}_{d,t}
=
G^{plan}_{d,t}
+PV^{act}_{d,t}
+D^{plan}_{d,t}
-C^{plan}_{d,t}.
\]

紧急购电量定义为：

\[
\boxed{
H^{act}_{d,t}
=
\max\left(
L^{act}_{d,t}-P^{net}_{d,t},0
\right)
}
\]

若实际供给富余，则记实际富余/弃电：

\[
V^{act}_{d,t}
=
\max\left(
P^{net}_{d,t}-L^{act}_{d,t},0
\right).
\]

实际总费用：

\[
\boxed{
Z_d^{real}
=
\sum_{t=1}^{T}
\left[
\pi_tG^{plan}_{d,t}
+5\pi_tH^{act}_{d,t}
\right]\Delta t
}
\]

注意：

1. 普通购电费始终按 0:00 的计划购电量计；
2. 紧急购电只作为实际负荷不足的补充；
3. 问题二不允许像问题三那样在 6:00、12:00、18:00 根据新预测修改普通计划购电量；
4. 这正是问题二与问题三的核心递进关系。

# 7.6 SOC 在第二部分中的处理

计划 SOC 按：

\[
E^{plan}_{d,t}
=
E_{d,t-1}
+0.90C^{plan}_{d,t}\Delta t
-\frac{D^{plan}_{d,t}\Delta t}{0.90}.
\]

【当前确认口径】紧急购电只用于弥补实际负荷缺口，不主动改变当天 0:00 已制定的储能充放电计划，因此：

\[
E^{real}_{d,t}=E^{plan}_{d,t}.
\]

日末状态传递：

\[
E_{d+1,0}=E^{real}_{d,T}.
\]

这样可避免在“实际结算阶段”再次使用全天真实未来数据重新优化储能，从而破坏第二部分的因果性。

如编程侧认为该口径造成大量“因计划充电而触发紧急购电”的非物理现象，请**不要自行修改模型**，单独回传统计结果，由建模手再决定是否增加“日内储能实时纠偏”扩展。

# 14. 论文建议叙述逻辑

问题二论文建议按两层写：

### 第一层：理想信息模型

> 首先直接依据题目提供的完整实际负荷与光伏序列，构建完美信息下的逐日滚动 MILP。该模型给出了理论基准。由于正常购电成本始终低于 5 倍紧急购电成本且未来缺口完全可知，最优解会提前安排正常购电，因此紧急购电趋于 0。

### 第二层：现实信息改进

> 然而，实际运行中每天 0:00 不可能准确预知当天所有真实负荷和光伏出力。为消除完美预见假设，本文仅利用历史已实现数据，以同星期滚动均值预测全天计划输入，再求解同结构 MILP。全天计划确定后不再修改普通购电量，当真实净负荷高于计划供能能力时，以 5 倍电价紧急购电。由此形成“预测—计划—实际结算”的因果调度流程。

### 两层关系

> 第一部分用于衡量理想信息条件下的费用下界；第二部分体现现实可执行策略。两者的费用差和紧急购电量共同反映预测误差带来的调度代价，并为问题三进一步利用 6:00、12:00、18:00 新预测进行计划调整提供自然递进。

# 15. 当前最终结论

问题二正式采用：

\[
\boxed{
\text{第一部分：完美信息下全年逐日滚动 MILP 基准}
}
\]

和：

\[
\boxed{
\text{第二部分：历史同周期预测 + 全年逐日滚动 MILP + 5 倍紧急购电结算}
}
\]

两部分使用同一套问题一符号和物理约束，区别只在于：

\[
\boxed{
\text{0:00 可获得的信息不同}
}
\]

第一部分使用当天实际值；第二部分严格只使用历史数据预测当天值。

**时间标签最新确认：`0:10` 电价对应 `[0:10,0:20)`。该口径优先于此前所有旧文档中的“结束时刻标签”解释。**
