# 6. 电价预测模型

## 6.1 模型选择

【复习清单内】

采用与问题二负荷/光伏预测相同的“同周期历史回溯 + 偏差校正”思想。

电价预测模块应尽量复用问题二预测框架的数据接口和验证方式。

## 6.2 基础价格预测

每天 \(d\) 的 0:00，只使用：

\[
\tau<d
\]

已经发生的历史真实价格。

建立未来 7 日价格中心预测：

\[
\boxed{
\hat\pi^{(d)}_{\tau,t},
\qquad
\tau=d,d+1,\ldots,d+6
}
\]

建议直接使用问题二“同星期回溯”的同类规则：

- 以历史相同星期位置的完整日电价曲线作为主要参照；
- 保留最近历史样本；
- 不使用决策日及以后真实价格。

具体历史加权参数应与问题二现有预测模块的参数化风格一致，避免另立完全不同的预测体系。

## 6.3 偏差校正

正式规定：

\[
\boxed{\text{价格预测保留偏差校正模块}}
\]

因为价格同样可能存在系统性高估或低估。

偏差校正只能利用决策时刻之前已经产生的预测误差。

不得用未来真实价格反向修正当前预测。

# 8. 三类误差必须联合抽样

问题四最大的新增风险，是：

\[
L,\quad PV,\quad \pi
\]

三类未来量可能存在相关性。

例如：

- 高温天气可能同时提高负荷和电价；
- 晴天可能提高光伏并影响峰谷购电；
- 某些日期的负荷峰值和价格峰值可能同步。

因此正式规定：

\[
\boxed{
\text{负荷误差、光伏误差、电价误差从同一历史误差日联合抽取}
}
\]

禁止：

- 单独抽负荷误差日；
- 再随机抽另一天光伏误差；
- 再随机抽第三天价格误差。

否则会人为破坏三者历史相关结构。
