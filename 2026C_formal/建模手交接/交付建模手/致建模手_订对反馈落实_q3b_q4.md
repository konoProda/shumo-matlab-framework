### 修正 3｜Q4-3 日内价格预测的因果校正公式已写明 ✅

**原表述（已废弃）**："并入当天已实现时段的同小时残差。"——你指出的问题成立：6:00 只有
0:00–6:00 的误差，这些样本只落在已过去的几个小时上，**根本影响不到 14:00/18:00/22:00**，
等于"更新了但未来时段没变"。

**正式公式（采用）**：设阶段 `s`，当天已实现时段集合 `Ω_s`（槽 1…6s），则

```
b_{d,s} = (1/|Ω_s|) · Σ_{t ∈ Ω_s} [ π^act_{d,t} − π̂^{(d,0)}_{d,t} ]        ← 当日水平偏差

π̂^{(d,s)}_{d,t} = π̂^{(d,0)}_{d,t} + b_{d,s},      t > 6s（当天尚未执行时段）
π̂^{(d,s)}_{τ,t} = π̂^{(d,0)}_{τ,t},                τ > d（未来日不变）
```

**四项要求的逐条满足**：

| 你的要求 | 该公式如何满足 |
|---|---|
| ① 只用时刻 s 之前已实现的真实价格 | `Ω_s` 只含槽 1…6s，全部已实现 |
| ② 不使用未来真实价格 | 公式中不出现任何 `t > 6s` 的实际值 |
| ③ 能说明当天整体偏高/偏低时未来预测为何变化 | `b` 是**当天整体的水平偏差**（不是逐小时），它按定义作用于当天**全部尚未执行时段**——6:00 观测到当天全体偏高，14:00/18:00/22:00 的预测同步上调 |
| ④ 公式可复现、可检验 | 公式只依赖已实现价格与 0:00 中心预测，可逐日逐阶段重算复核；检验项见下 |

**关于未来日不传导的说明**：未来日的价格中心预测在次日 0:00 会被完全重建（方案文档 §31
"预测可跨日用于估值，正式计划每天重新建立"），日内不做跨日传导——因为跨日传导的强度
缺乏数据依据，若引入衰减系数就成为一个无依据的自由参数。**若建模侧希望跨日传导，
请给出衰减系数的取值依据，编程侧再补。**

**配套检验（新增，写入 /test）**：
- **T14 价格更新因果性**：同一日期，改动 6:00 之后的真实价格，6:00 阶段的 `b` 与 6:00 之后
  的中心预测**必须逐槽不变**；
- **T15 更新有效性**：同一日期，改动 0:00–6:00 的真实价格，6:00 阶段当天剩余时段的中心预测
  **必须发生与该改动同向的变化**（防止"更新了但没变"）。

### 修正 4｜阶段流程已改写为"求解—执行—更新—再求解" ✅

**原表述（已废弃，易被误读）**："执行层可以把最终计划拼接后一次性执行，逐槽等价。"

**新表述（正式采用）**：

> **阶段求解必须边执行、边更新真实状态**：
> 0:00 求解 → 执行到 6:00 → （取得真实储电量与已实现价格）→ 6:00 求解 → 执行到 12:00 →

第二段（重放复核）**已作为一项强制一致性检验**写入 /test：同一日两条路径得到的

## 二、保护性检查：已实测并升级为正式加固（并获建模侧批准）

### 实测事实（先报数）

对 337 个决策日的 0:00 阶段价格情景逐日求最小值：

| 项 | 实测 |
|---|---|
| 情景最小值（全局） | **−0.0523 元/kWh** |
| 出现负情景的决策日 | **28/337（8.3%）** |
| 负情景日的最小值分位（1%/5%） | −0.0418 / −0.0218 |
| 实际价格最小值 | 0.0076 元/kWh；残差最小值 −0.4233 |

⇒ **负价格情景不是偶发，而是必然会出现的**，你的保护性检查会被触发。
且问题比预想更严重：**负价下 Δ⁺/Δ⁻ 的线性化松弛不但不再保证单边，目标还会向下无界**。

### 已按建模侧批准的规格实现（H-1 + H-2）

**H-1｜正常购电计划的物理上界**（替代原人工 `1e5`）：

```
当前日原计划与各阶段调整计划： 0 ≤ P_{d,t}, A^s_{d,t} ≤ U_{d,t},
                              U_{d,t} = max_ω L̄^{(ω)}_{d,t} + 5000

未来日情景内临时计划：        0 ≤ G^{plan,(ω)}_{τ,t} ≤ L̄^{(ω)}_{τ,t} + 5000
```

- 含义：正常购电最多只能用于"补负荷 + 最大充电功率"；
- `W` 保留，只表示预测误差造成的已购未用电；
- **`U_{d,t}` 在当天 0:00 阶段算定后对该日四个阶段冻结**（否则各阶段情景不同会导致
  `U` 不一致，可能出现 `A^s` 上界低于已锁定的 `P`，从而被迫调减）；
- **对价格为正的场景恒不起作用**：正价下 `W` 无利可图，最优解必有 `W = 0`，
  于是 `G^plan = G^L + G^ch ≤ max_ω L̄ + 5000`。故该上界**不改变问题二、问题三的结果**，
  也不改变问题四在正价时段的结果。

**H-2｜调增/调减互斥**（不再依赖"价格为正"的隐式论证）：

```
A − P = Δ⁺ − Δ⁻,   0 ≤ Δ⁺ ≤ M_t·z,   0 ≤ Δ⁻ ≤ M_t·(1 − z),   z ∈ {0,1},   M_t = U_{d,t}
```

- **不引入人工 Big-M**，直接取 `M_t = U_{d,t}`；
- 正价下原最优解本就取单边，故此约束**不收紧最优值**；负价下它把"调增/调减互斥"显式化，
  使结算式**严格等于**方案文档 §19.3 定义的语义；
- 模型仍是 SAA-MILP，求解器与分支定界/分支切割体系不变。

**负价格情景保留、不截断为 0**；"检测到负价即停机回报"的保护要求已按建模侧批复**解除**。

### 对规模与机时的影响

每个阶段新增 `Tcur` 个二元变量（0:00 阶段 144、6:00 阶段 108、12:00 阶段 72、18:00 阶段 36，
