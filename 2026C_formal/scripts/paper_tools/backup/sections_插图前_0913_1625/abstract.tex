\begin{center}{\zihao{2}\heiti 基于能量分流与滚动随机优化的微网购电调控研究}\end{center}

\vspace{0.6em}
\begin{center}{\zihao{4}\heiti 摘\quad 要}\end{center}
\vspace{0.4em}
{\zihao{-4}

针对含光伏、储能和外部电网的微网购电调控问题，本文从确定性调度、日前计划、日内预报更新和实时电价波动四个层次展开研究。首先建立能量分流混合整数线性规划模型，明确光伏供负荷、储能充放电、外网购电和弃光之间的物理关系；进一步引入历史预测误差和情景抽样，构造7日滚动两阶段随机模型；在此基础上加入0:00、6:00、12:00、18:00多时点预报更新和阶段调整机制；最后将实时电价预测及负价格情景纳入联合不确定性优化。结果表明，问题一单日购电费用为35126.95元，较无储能方案降低26.90%，且弃光量为0；问题二正式口径下报送窗口总费用为14806890.28元，紧急购电量为269240.9 kWh；问题三采用四个预报时点时总费用为14485230.30元，紧急购电量为185524 kWh；问题四中，日内价格更新使对应问题二的费用由16320514.83元降至15225713.07元，降幅6.71%。各模型均通过能量守恒、储能边界、整数可行性和阶段拼接检验。灵敏度检验部分暂留待补。

\noindent\textbf{关键词：}微网调度；储能优化；能量分流；随机规划；滚动优化；电价预测
}
